# figure 配 figcaption 写图注

## 简单示例（figure、figcaption）

一张图要配一句说明，用 `figure` 把图和说明包在一起。说明写在 `figcaption` 里。

和 `img` 那篇一样，先在 `index.html` 旁边放一张图片，文件名用 `cover.png`。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>图注</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <p>封面长这样。</p>
  <figure>
    <img src="cover.png" alt="深色背景上的白色标题">
    <figcaption>图 1：这门课的封面。</figcaption>
  </figure>
</body>
</html>
```

保存后用浏览器打开。图的下方有一行「图 1：这门课的封面。」图能显示时，读者看见的是图，再加上这行说明。`cover.png` 找不到时，图的位置上是 `alt` 里的「深色背景上的白色标题」，说明那一行仍在。

## 标签介绍（概念和特征）

`figure` 表示一块可以单独挪走的内容，再配一句说明。这一篇用它装一张图和它的图注。它自己占一块，浏览器通常在左右留出一段空白，和 `blockquote` 一样，是附带的样子。插在句子中间、没有单独说明的图，继续只用 `img`。

`figcaption` 是这块的说明。它必须写在 `figure` 里面，而且是里面的第一个或最后一个。一个 `figure` 只放一个 `figcaption`。示例里它写在 `img` 后面，所以出现在图的下方。写在 `img` 前面，说明就出现在图的上方。

`alt` 和 `figcaption` 各写各的。`alt` 是图加载失败、或读屏不看图时，用来代替这张图的文字。`figcaption` 是图还在的时候，页面上也看得见的说明。说明已经把画面说完、图本身没有更多信息时，`alt` 写成空字符串，规则和 `img` 那篇相同。

| | `alt` | `figcaption` |
|---|---|---|
| 写在哪 | `img` 上 | `figure` 里面，第一个或最后一个 |
| 图能显示时 | 页面上不出现这句 | 出现在图的上面或下面 |
| 图加载失败时 | 读者看到这句 | 说明仍在 |

页头里的小标志、一句话中间的小图，没有单独的说明，不用 `figure`。

## 要点总结

1. 图和它的说明要绑在一起，用 `figure` 包住。说明放进 `figcaption`。
2. `figcaption` 是 `figure` 的第一个或最后一个子元素，只能有一个。
3. `alt` 代替图片，`figcaption` 是看得见的说明。两句各写各的。
4. 没有单独说明的图，只用 `img`。
