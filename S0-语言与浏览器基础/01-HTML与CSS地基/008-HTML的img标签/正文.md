# img 的 src 和 alt 各写什么

## 简单示例（img、src、alt）

`img` 用 `src` 指出图片在哪，用 `alt` 写出这张图在告诉读者什么。先在 `index.html` 旁边放一张图片，文件名用 `cover.png`。外壳不动，`body` 换成下面这样，保存，刷新。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>插入图片</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <img src="cover.png" alt="课程封面：深色背景上的白色标题">
  <img src="missing.png" alt="这张图没有加载出来">
</body>
</html>
```

`cover.png` 能找到时，第一张图显示出来。`missing.png` 并不存在，第二张的位置上出现「这张图没有加载出来」。那就是 `alt` 里的字。

这一篇先把图放出来。不写 `width`，也不写 `height`。图有多宽，先用图片自己的尺寸。

## 标签介绍（概念和特征）

`<img src="地址" alt="替代文字">`。`img` 是空元素，没有结束标签，不要写 `</img>`。

`src` 的写法和上一篇链接地址相同。同一文件夹写 `cover.png`，子文件夹写 `images/cover.png`，上一级写 `../cover.png`，另一台服务器写完整的 `https://` 地址。图没出现时，先看它最后拼出来的地址，和链接打不开时一样。

`alt` 是替代文字，不是图片标题，也不出现在图的旁边。图能显示时，读者看见图。图加载失败，或者读屏软件不看图、只读文字时，用的就是这句。句子要写出这张图在告诉读者什么。封面在告诉人「这是一门课的封面，上面有标题」，就写成那句话，不要写成「图片」或文件名。

图只是装饰，旁边的文字已经把事情说清了，`alt` 留空：`alt=""`。属性还在，值是空的。不要把整个 `alt` 删掉。删掉之后，读屏软件可能会改读文件名，失败时页面上也没有一句人话。

`alt` 和图下面另写的一句说明不是同一句。把图和说明包在一起，是后面「图片和它的说明」那一篇。

## 要点总结

1. `img` 的 `src` 写图片地址，写法和链接地址相同。它是空元素，没有结束标签。
2. `alt` 写出这张图在告诉读者什么。图加载失败时，读者看到的就是这句。
3. 纯装饰、旁边文字已经说清的图，写成 `alt=""`。不要删掉 `alt`。
4. 这一篇不写死宽和高。
