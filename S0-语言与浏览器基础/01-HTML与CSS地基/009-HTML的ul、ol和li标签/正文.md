# ul、ol、li 怎么写一组列表

## 简单示例（ul、ol、li）

没有先后的一组用 `ul`，步骤或名次用 `ol`。每一条都是 `li`。外壳不动，`body` 换成下面这样，保存，刷新。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>列表</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <h2>这门课会用到</h2>
  <ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript
      <ul>
        <li>这一项先不学</li>
      </ul>
    </li>
  </ul>
  <h2>打开页面的步骤</h2>
  <ol>
    <li>保存为 index.html</li>
    <li>用浏览器打开</li>
    <li>改完之后刷新</li>
  </ol>
</body>
</html>
```

`ul` 的三条前面是圆点。其中「JavaScript」下面还有一层圆点。「打开页面的步骤」三条前面是 1、2、3。圆点和数字都是浏览器画的，源码里没有写 `·` 或 `1.`。

## 标签介绍（概念和特征）

`ul` 是没有顺序的一组：顺序换一换，意思不变，例如一门课会用到的几样东西。`ol` 是有顺序的一组：步骤、名次、操作先后。选哪一个，先问「把两条对调，意思变不变」。

`li` 是其中一条，必须放在 `ul` 或 `ol` 里面。`ul` 和 `ol` 的直接子内容就是这些 `li`，不要把一段 `p` 直接放进 `ul`。

某一条下面还可以再套一层列表。内层的 `ul` 或 `ol` 写在那一条 `li` 里面，不要写在 `li` 的外面、和别的 `li` 平级。示例里「这一项先不学」属于「JavaScript」这一条，所以套在它的 `li` 里。内层用 `ul` 还是 `ol`，仍看那一层有没有先后。

圆点和数字是浏览器的默认样式。换成方块、改成从 3 开始数，是后面 CSS 的事。这一篇不在标签上写编号。

列表用来放一组并列的条目。页面左右分栏、做导航的外观，先不要用列表来硬排。导航链接以后有自己的结构。

## 要点总结

1. 没有先后用 `ul`，步骤或名次用 `ol`。对调两条之后意思变了，就用 `ol`。
2. 每一条都是 `li`，放在 `ul` 或 `ol` 里面。
3. 再套一层时，把新的列表写进那一条 `li` 里。
4. 圆点和数字是浏览器默认画的，源码里不用自己写。
