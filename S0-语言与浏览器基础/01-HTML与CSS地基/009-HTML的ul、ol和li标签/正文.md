# ul、ol、li 怎么写一组列表

## 简单示例（ul、ol、li）

在html中，ul代表无序列表。ol代表有序列表。li代表列表项。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>列表</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <h2>这门课会用到</h2>
  <ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript
      <ul>
        <li>这一项先不学</li>
      </ul>
    </li>
  </ul>
  <h2>打开页面的步骤</h2>
  <ol>
    <li>保存为 index.html</li>
    <li>用浏览器打开</li>
    <li>改完之后刷新</li>
  </ol>
</body>
</html>
```

从展示效果上看：

ul、li的组合，列表的每一项前面都是一个圆点。

ol、li的组合，列表的每一项前面都是数字。

## 标签介绍（概念和特征）

`ul` 是没有顺序的一组：顺序换一换，意思不变，例如一门课会用到的几样东西。

`ol` 是有顺序的一组：步骤、名次、操作先后。选哪一个，先问「把两条对调，意思变不变」。

`li` 是其中一条，必须放在 `ul` 或 `ol` 里面。`ul` 和 `ol` 的直接子内容就是这些 `li`。

`ul`、`ol` 他们的子元素一定是 `li`。

嵌套结构：`li`中，也可以包裹一组列表。但是必须放在 `li` 内部。

某一条下面还可以再套一层列表。内层的 `ul` 或 `ol` 写在那一条 `li` 里面，不要写在 `li` 的外面、和别的 `li` 平级。示例里「这一项先不学」属于「JavaScript」这一条，所以套在它的 `li` 里。内层用 `ul` 还是 `ol`，仍看那一层有没有先后。

圆点和数字是浏览器的默认样式，列表用来放一组并列的条目。

## 要点总结

1. `ul` 代表无序列表，`ol` 代表有序列表。
2. `li` 代表每一项，放在 `ul` 或 `ol` 里面。
3. `li` 的子元素可以是任意元素。但是`ul` 和 `ol` 的直接子元素必须是 `li`。
