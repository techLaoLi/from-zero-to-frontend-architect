# input 密码框邮箱框怎么写？textarea 多行

**`input` 的 `type` 属性决定输入框的种类：`password` 是密码框，`email` 是邮箱框，`number` 是数字框，`textarea` 是可以写多行的文本框。** 这几个框的写法都是 `input` 加一个不同的 `type`。

本文解决一个具体问题：密码、邮箱、数字、多行说明这几种输入，各该用哪个标签写。

## password、email、number 三种输入框

结构完全一样，只是 `type` 换了值。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>注册</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <form action="index.html" method="get">
    <p>
      <label for="pw">密码</label>
      <input type="password" id="pw" name="pw">
    </p>
    <p>
      <label for="mail">邮箱</label>
      <input type="email" id="mail" name="mail">
    </p>
    <p>
      <label for="age">年龄</label>
      <input type="number" id="age" name="age">
    </p>
    <button type="submit">提交</button>
  </form>
</body>
</html>
```

这段代码演示的是三种不同的输入框。跑完你会看到：密码框里打进去的字显示成一排圆点，看不到原文；邮箱框和数字框都是单行，但键盘弹出来时不一样，邮箱是带 `@` 的键盘，数字是数字键盘。

**密码框用 `type="password"`。** 输入的内容在页面上被遮住，但注意——遮住只是显示上的，提交出去的仍然是原文。

**邮箱框用 `type="email"`。** 浏览器会检查内容像不像一个邮箱，不像就拦下来不让提交。

**数字框用 `type="number"`。** 只接受数字。有些浏览器在框的右边会带上下两个小箭头，点箭头数字加一减一。

## textarea 写多行文字

要写好几行，用 `textarea`，不是 `input`。

```html
<label for="intro">自我介绍</label>
<textarea id="intro" name="intro" rows="4" cols="40"></textarea>
```

这段代码演示的是一个能写四行的文本框。跑完你会看到：框比输入框高，能敲回车换行，光标进去以后可以用 Tab 键跳出去。

**`textarea` 是成对的标签**，写成 `<textarea></textarea>`，内容写在中间。`input` 是空标签，自己就结束了。

`rows` 写几行高，`cols` 写几列宽。这一阶段先这么写，具体外观以后用样式调整。

`textarea` 里面也能写 `name`、`id`，规则和输入框一样。

## type 决定浏览器怎么检查

`type` 不只是换个外观，它还决定了浏览器怎么对待你填的内容。

| type | 接受什么 | 提交时的检查 |
|---|---|---|
| `text` | 任何文字 | 不检查 |
| `password` | 任何文字 | 不检查，页面上遮住 |
| `email` | 像邮箱的字符串 | 不像邮箱就不让提交 |
| `number` | 数字 | 不是数字就不让提交 |

`email` 和 `number` 的检查是浏览器自己做的，弹出的是浏览器自己的提示框，不是我们自己写的。

这一篇只讲框本身。空不空、最多填多少字、填的内容合不合格，放到后面的检查那一篇。

## 要点总结：按输入类型选框

1. 单行普通文字用 `input type="text"`，密码用 `password`，邮箱用 `email`，数字用 `number`。
2. `password` 只是页面上不显示原文，提交出去的仍是原文。
3. `email` 和 `number` 会让浏览器自己检查内容，检查不通过不让提交。
4. 多行文字用 `textarea`，它有成对的标签，写法是 `<textarea></textarea>`。
