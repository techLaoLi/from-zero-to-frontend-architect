# article 和 section 差在哪

## 简单示例（article、section）

能单独拿走、单独读懂的一篇，用 `article`。这篇里面按主题切开的一节，用 `section`。

还用上一篇的页头和页脚。`body` 换成下面这样，保存后刷新。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>一篇和一节</title>
</head>
<body>
  <header>
    <p>前端课程</p>
  </header>
  <main>
    <article>
      <h1>前端从零到架构师</h1>
      <p>这是一篇可以单独转发的课程介绍。</p>
      <section>
        <h2>这门课会用到</h2>
        <p>先写 HTML，再写 CSS。</p>
      </section>
      <section>
        <h2>适合谁</h2>
        <p>给零基础、准备自己做一张页面的人。</p>
      </section>
    </article>
  </main>
  <footer>
    <p>本页只讲结构。</p>
  </footer>
</body>
</html>
```

页面上仍是标题和段落上下排开，没有新的颜色。`article` 和 `section` 自己占一块，样子和 `div` 接近。

把 `article` 整段复制到另一页，标题、介绍和两节都在，还是一篇完整的课程介绍。只把「适合谁」拿走，它只是介绍里的一节。

## 标签介绍（概念和特征）

先问一句：这块单独发到别处，读者不看上下文，还能读懂吗？

能读懂，用 `article`。一篇课程介绍、一条可以单独转发的笔记，都是这种。`article` 里写上它的标题。这一页的最高标题仍是那一个 `h1`，放在 `article` 里。`main` 包在 `article` 外面。

只是全文里的一个主题，用 `section`。「这门课会用到」和「适合谁」都要跟着全文才完整，所以是 `section`，标题用 `h2`。

`section` 里面写上标题，读者才看得出这一节在讲什么。没有主题、也不打算给它标题、只是为了包住一块，用 `div`。

两层可以反过来套，意思不同：

| 外层 | 里层 | 什么时候 |
|---|---|---|
| `article` | `section` | 一篇完整的文章，里面分几节 |
| `section` | `article` | 一栏里放好几篇，每一篇都能单独读 |

这一篇的示例是第一种。第二种例如页面上有一块「最近的笔记」：那一块是 `section`，里面每条笔记各是一个 `article`。

## 要点总结

1. 单独拿走仍读得懂，用 `article`，并给它一个标题。
2. 只是全文里的一个主题，用 `section`，标题跟着写。
3. 没有主题、只为包住一块，用 `div`。
4. 一篇文章里分几节，是 `article` 里面放 `section`。`main` 留在 `article` 外面。
