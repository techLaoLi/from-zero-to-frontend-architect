# colspan 和 rowspan 怎么用？表格合并单元格

**`colspan` 和 `rowspan` 是写在 `th` 或 `td` 上的属性：`colspan="2"` 让这个格子向右占两列，`rowspan="2"` 让这个格子向下占两行。** 被合并掉的位置，不用再写格子。

本文解决一个具体问题：一张表里想让某几个格子连成一片，HTML 里怎么写。

## colspan 让一个格子横着占多列

横着合并用 `colspan`，值写它要占几列。

```html
<table>
  <tr>
    <th colspan="2">前端课程</th>
    <th>难度</th>
  </tr>
  <tr>
    <td>HTML</td>
    <td>CSS</td>
    <td>入门</td>
  </tr>
</table>
```

这段代码演示的是一个表头横着占两列。跑完你会看到：第一行的「前端课程」占掉了左边两个格子的宽度，和下面的「HTML」「CSS」两列对齐。

值是几，就占几列。`colspan="2"` 占两列，`colspan="3"` 占三列。

## rowspan 让一个格子竖着占多行

竖着合并用 `rowspan`，值写它要占几行。

```html
<table>
  <tr>
    <th>标签</th>
    <th>用途</th>
  </tr>
  <tr>
    <td rowspan="2">div</td>
    <td>包住一组内容</td>
  </tr>
  <tr>
    <td>自己占一块</td>
  </tr>
</table>
```

这段代码演示的是一个数据格竖着占两行。跑完你会看到：第二行的「div」这一格占了两行的高度，和右边的「包住一组内容」「自己占一块」两行对齐。

## 被占掉的位置不用再写 td

这是最容易写错的地方。

**合并掉的格子位置，不写任何标签。** 上面的例子里，`rowspan="2"` 那个 `div` 已经占了两行，所以第二行只需要写右边那个 `td`，左边不能再补一个空的 `td`。

补了会怎样？浏览器会以为那一格有内容，多出一格，表格就错位了。

写之前先在纸上把格子画出来。画出几行几列、哪个格子占了几行几列，再对着格子写标签，就不容易错。

## 要点总结：合并单元格的三个规则

1. `colspan` 横着合并，值写占几列；`rowspan` 竖着合并，值写占几行。
2. 写在 `th` 或 `td` 的开始标签里，和其他属性并列。
3. 被占掉的位置不写任何标签。写之前先在纸上画出格子。
