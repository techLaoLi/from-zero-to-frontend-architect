# br 换行，hr 画出一条横线

## 简单示例（空格、br、hr、&nbsp;）

空格、回车、`br`、`hr` 各做一件事。外壳不动，`body` 换成下面这样，保存，刷新。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>空格、换行和横线</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <p>第一句在这里。    后面连着按了四个空格。
再按一次回车，这句仍在同一段里。</p>
  <p>同一段里要换行，用 br。<br>这一行还是上面那段。</p>
  <p>这是新的一段。段与段的空隙来自两个 p。</p>
  <hr>
  <p>话题换了。价格写成 99&nbsp;元，数字和「元」中间这个空格不会被拆开。</p>
</body>
</html>
```

你会看到：第一段里的四个空格和那次回车，页面上只剩一个空格。`br` 那一行在段落中间换了行。两个 `p` 之间有一块空隙。`hr` 是一条横线。`99` 和「元」贴着一个不会断开的空格。

## 标签介绍（概念和特征）

浏览器读正文时，会把源码里连续的空格、制表和回车收成一个普通空格。所以多按几下空格，页面上不会空出一截；多按几次回车，也不会多出一段。

| 写法 | 页面上是什么 |
|---|---|
| 连续空格、回车 | 多半只剩一个空格 |
| `<br>` | 同一段里换一行 |
| 再写一个 `p` | 新的一段，中间有默认空隙 |
| `<hr>` | 话题换了，画出一条横线 |
| `&nbsp;` | 一个不会被拆开的空格 |

`<br>` 是空元素，没有结束标签，不要写 `</br>`。它只换行，不开始新的一段。换行前后仍是同一个 `p`。

`<hr>` 也是空元素。它表示话题从这里断开，浏览器把它画成一条横线。横线上下要各是完整的内容，不要用它去代替两个 `p` 之间的空隙。

段与段的空隙靠两个 `p`。上一篇讲过，这个空隙是浏览器给 `p` 的默认样式。想靠回车把两段撑开，回车会被收成空格，空隙不会出现。

`&nbsp;` 是一个不换行空格（non-breaking space）。它占一个空格的位置，并且不允许浏览器在这个位置把行断开。`99&nbsp;元` 会尽量整段留在同一行。它不能用来把两块内容推开，也不能用来做缩进。推开和缩进是后面 CSS 的事。连写很多个 `&nbsp;`，只是得到很多个不换行空格。

要按源码原样保留每一行空格和回车，用后面「在页面里放一段代码」里的 `pre`。这一篇的正文不保留那些回车。

## 要点总结

1. 源码里连着的空格和回车，页面上多半只剩一个空格。
2. 同一段里换行用 `<br>`。这仍是这一段。新的一段再写一个 `p`。
3. `<hr>` 表示话题换了，页面上是一条横线。
4. `&nbsp;` 是一个不会被拆开的空格。不要用它把两块内容推开。
