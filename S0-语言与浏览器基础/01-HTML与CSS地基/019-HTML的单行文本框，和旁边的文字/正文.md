# input text 怎么写？label 和 placeholder

**单行文字输入用 `<input type="text">`，它旁边的说明文字用 `label` 包起来，`label` 的 `for` 写成输入框的 `id`，两者就绑在了一起。** `placeholder` 是框里显示的示例提示，提交时真正带走的值来自 `name`。

本文解决一个具体问题：一张表单上的输入框，旁边那句「姓名：」该怎么写，为什么光放一个输入框还不够。

## input type="text" 写出来的文本框

`input` 是输入标签，`type` 决定它是哪一种。`type="text"` 是最普通的那种单行文字框。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>报名</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <form action="index.html" method="get">
    <p>
      <label for="username">用户名</label>
      <input type="text" id="username" name="username">
    </p>
    <button type="submit">提交</button>
  </form>
</body>
</html>
```

这段代码演示的是一个带说明文字的输入框。跑完你会看到：左边是「用户名」三个字，右边是一个可以点进去打字的框。

点「用户名」这三个字，光标同样会跳进框里。这就是 `for` 和 `id` 配对的作用。

## label 的 for 和 input 的 id 怎么配对

| 属性 | 写在哪个标签 | 填什么 |
|---|---|---|
| `id` | `input` | 这个框自己的标识，一页里不重复 |
| `for` | `label` | 要指认的那个框的 `id` |

两个值要**完全一致**，包括大小写。`for="username"` 对上 `id="username"`，就绑住了。

配对了才有三个好处：点文字能聚焦框、屏幕阅读器会连着念出标签、用键盘 Tab 过去时知道这是干什么的框。

写错了会怎样？把 `for` 改成 `for="userName"`，点文字就聚焦不进去了。

## placeholder 和 name 各是什么

| 属性 | 作用 | 提交时 |
|---|---|---|
| `placeholder` | 框里显示的示例提示 | 不带走 |
| `name` | 这个字段的提交名字 | 带走 |

**`placeholder` 是给填写的人看的提示。** 比如写「例如：张三」，提示用户这里该填什么。它是浅色的灰字，一旦开始输入就消失。

`placeholder` 不能替代 `label`。很多读者一进来就看不到提示了，屏幕阅读器也不一定念它，所以框外面仍然要有 `label`。

**`name` 是提交时用的字段名。** 上一篇说过，`get` 提交后地址栏里带的正是 `name` 的值。写了 `name="username"`，地址栏才会出现 `username=xxx`。

所以一个输入框通常要写三样：`type` 决定种类、`id` 供 `label` 指认、`name` 供提交使用。

## 要点总结：文本框的四个部分

1. 输入框写 `<input type="text">`，`type` 决定它是哪一种框。
2. 框外的说明文字用 `label`，`for` 和框的 `id` 必须完全一致。
3. `placeholder` 是框里的提示，填了就被盖住，不能替代 `label`。
4. `name` 是提交时的字段名，会出现在地址栏里，不能漏。
