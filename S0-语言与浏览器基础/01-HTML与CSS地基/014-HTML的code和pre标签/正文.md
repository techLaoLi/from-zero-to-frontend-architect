# code 标出代码，pre 保留换行

## 简单示例（code、pre）

句子里的一小段代码用 `code`。要按写下的空格和换行原样显示一整段，用 `pre`，里面再套 `code`。

把下面存成 `index.html`，用浏览器打开。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>代码</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <p>段落标签写成 <code>&lt;p&gt;</code>，这几个字还在这句话里面。</p>
<pre><code>&lt;h1&gt;前端从零到架构师&lt;/h1&gt;
  &lt;p&gt;这是一段。&lt;/p&gt;</code></pre>
</body>
</html>
```

第一段里的 `<p>` 是等宽字，留在这句话中间。下面那一块是两行，第二行没有并进第一行。第二行行首有两个空格，页面上也能看见。这两个空格是故意写在 `pre` 里面的。

`pre` 这一行没有跟着上面的标签缩进。缩进也是空格，写进去就会显示出来。

两处尖括号能看见，是因为写成了 `&lt;` 和 `&gt;`。直接写 `<p>`，浏览器会把它当成真的段落标签。

## 标签介绍（概念和特征）

`code` 表示这几个字是代码：一个标签名、一个属性、一小段写法。它是行内标签，不自己另起一块。浏览器通常改用等宽字体。空格和换行仍按普通正文合并：连续空格收成一个，换行也不另起一行。

`pre` 表示里面的空白是内容的一部分。空格、换行都保留，并且自己占一块。浏览器通常也用等宽字体。`pre` 只说明按写下来的样子排，并不说明这是代码。一段要保留换行的文字，也可以只用 `pre`。

一段代码要两样都标明：这是代码，而且换行要留下。`pre` 写在外面，`code` 写在里面：

```html
<pre><code>这一段代码</code></pre>
```

只把那两行放进 `code`、外面没有 `pre`，换行会被收成空格，两行并成一行。只写 `pre`、不写 `code`，换行还在，但这块没有被标成代码。

顺序是 `pre` 在外、`code` 在里。写成 `code` 包住 `pre` 时，换行往往还在，页面也不会报错，但这不是这段代码该有的套法。

尖括号的规则和实体那一篇相同。`code` 和 `pre` 不会把 `<` 变成可以显示的文字。要显示小于号，仍写 `&lt;`。

| | `code` | `pre` |
|---|---|---|
| 表示什么 | 这是代码 | 空白要原样保留 |
| 占不占一块 | 留在行内 | 自己占一块 |
| 换行 | 收成空格 | 留下 |
| 这一篇怎么一起用 | 包住代码本身 | 包在 `code` 外面 |

## 要点总结

1. 句子里的标签名、一小段代码，用 `code`。它留在行内，通常是等宽字。
2. 换行和空格要原样出现，用 `pre`。`pre` 自己不表示「这是代码」。
3. 一整段代码写成 `pre` 里面套 `code`。不要写成 `code` 里面套 `pre`。
4. 要显示尖括号，仍写成 `&lt;` 和 `&gt;`。
