# HTML 是什么？先分清三门语言

## 整体说明

浏览器打开的一页，来自三份说明，各管一件事：

- HTML：这页有什么
- CSS：它们长什么样
- JavaScript：人操作之后发生什么

三份说明通常是三个文件，也可以暂时写在同一个文件里。写在一起时，仍然按三门来认。

## HTML、CSS、JavaScript分别都是干什么的？

| | 回答的问题 | 常见文件 |
|---|---|---|
| HTML | 这页有哪些块，每一块是什么角色 | `.html` |
| CSS | 颜色、字号、间距、位置 | `.css` |
| JavaScript | 点击、输入、取数据之后，页面怎么变 | `.js` |

新建 `index.html`，用 UTF-8 保存，双击用浏览器打开。确认扩展名是 `.html`。改完刷新：Mac 用 `Cmd + R`，Windows 用 `F5`。地址栏以 `file:///` 开头，表示打开的是本地文件。

```html
<h1>前端从零到架构师</h1>
<p>这是一门给零基础的人准备的课程。</p>
```

这两行是 HTML。它标明第一块是标题，第二块是一段话，没有写颜色和字号。第一行为什么更大，留到讲标题的那一篇。

下面把 CSS 和 JavaScript 临时放进同一文件，只看它们各改哪一处。这两段写法现在不用记。

```html
<h1>前端从零到架构师</h1>
<p>这是一门给零基础的人准备的课程。</p>
<button>看一句分工</button>

<style>
  h1 { color: #c2410c; }
</style>

<script>
  document.querySelector("button").addEventListener("click", function () {
    document.querySelector("p").textContent = "标题仍然是标题，变的只有这句话。";
  });
</script>
```

刷新后标题变成深橙色，这是 `<style>` 里的 CSS 在改外观。点「看一句分工」，段落里的字被换掉，这是 `<script>` 里的 JavaScript。标题、段落、按钮这三块仍是 HTML。

删掉 `<style>` 和 `<script>` 再刷新。按钮还在，点下去没有后续动作。HTML 负责把按钮放上页面，点击之后的反应归 JavaScript。

本专栏从样式模块起，外观写在单独的 CSS 文件里。行为在专栏 02。

## HTML概念和定义

**HTML（HyperText Markup Language，超文本标记语言）是一种标记语言，用标签标明文档里每一块内容的角色，由浏览器解析后显示成页面。**

| 词 | 含义 |
|---|---|
| 标记语言 | 只做标注。没有变量、循环和判断，不能拿来做计算 |
| 超文本 | 一份文档可以链向另一份。链接怎么写，后面单独讲 |
| 标签 | 尖括号里的名字，标明角色。字号和颜色不由标签名决定 |
| 解析 | 浏览器按 HTML 的规则读这份文本，再显示成页面 |

HTML 文件里可以临时放入 `<style>` 和 `<script>`，浏览器认。读的时候仍把它们归到 CSS 和 JavaScript。

查名词用 MDN（`developer.mozilla.org`）。和规范对不上时，以 WHATWG 的 HTML Living Standard 为准。

## 验收标准

1. 能说出 HTML、CSS、JavaScript 各回答什么问题。
2. 能复述：HTML 是标记语言，用标签标明每一块内容的角色。
3. 打开自己的 `index.html`，指出哪些行是 HTML。文件里如果还留着 `style` 和 `script`，能把它们分别归到 CSS 和 JavaScript。
