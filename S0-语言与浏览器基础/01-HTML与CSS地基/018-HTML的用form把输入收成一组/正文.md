# form 标签是什么？表单怎么收集数据

**`form` 是 HTML 里把一组输入框收在一起的标签，浏览器会把 `form` 里面的内容作为一组数据一起提交。** 提交到哪里由 `action` 决定，用什么方式送出去由 `method` 决定。

本文解决一个具体问题：做一张能填写、能点提交的表，输入框和按钮该怎么包在 `form` 里。

## form 和它里面的输入框

`form` 本身不显示任何东西，它是一个看不见的容器，把里面的输入框和按钮圈成一组。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>报名</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <form action="index.html" method="get">
    <p>姓名：<input type="text" name="name"></p>
    <p>城市：<input type="text" name="city"></p>
    <button type="submit">提交</button>
  </form>
</body>
</html>
```

这段代码演示的是一张最简单的表单。跑完你会看到：页面上有两个输入框和一个「提交」按钮，`form` 本身在页面上看不出任何痕迹。

在两个框里各填点东西，点「提交」。因为 `method="get"`，浏览器会把页面换成 `index.html?name=xxx&city=xxx`，填的内容出现在地址栏的 `?` 后面。

输入框必须写在 `form` 里面。不在这个 `form` 里的输入框，点提交时不会被一起送出去。

## action 和 method 各是什么

| 属性 | 写在哪 | 表示什么 |
|---|---|---|
| `action` | `form` 的开始标签 | 数据提交到哪个地址 |
| `method` | `form` 的开始标签 | 用什么方式提交 |

**`action` 写提交到哪个地址。** 示例里写的是 `index.html`，意思是提交完仍然回到这个文件。实际项目里通常写一个服务器上的接口地址，比如 `action="/api/signup"`。

**`method` 写用什么方式。** 这一阶段只用 `get`。

`get` 的特点是，数据拼在地址栏后面，浏览器会把它放进浏览历史。用 `get` 提交密码或者身份证号，是不合适的。

还有一个 `post` 方式，数据放在请求体里，不出现在地址栏。这个阶段没有服务器，先不碰。

## get 提交后地址栏发生了什么

填好上面的表单点提交，地址栏会变成这样：

```
index.html?name=张三&city=西安
```

这一串就是浏览器拼出来的数据。

`?` 后面是所有字段，`name` 是左边，值是右边，中间用 `&` 分开。字段的名字来自每个输入框的 `name` 属性——所以输入框一定要写 `name`，否则它就不会出现在这里。

`?` 后面只有这一组数据，因为这个页面只有一个 `form`。一个页面有多个 `form` 时，每个都会自己拼一组。

## 要点总结：表单的三个概念

1. `form` 把输入框和按钮收成一组。框写在 `form` 里面，才会被一起提交。
2. `action` 写提交到哪，`method` 这一阶段只用 `get`。
3. `get` 提交后，数据出现在地址栏 `?` 后面，字段名来自输入框的 `name` 属性。
