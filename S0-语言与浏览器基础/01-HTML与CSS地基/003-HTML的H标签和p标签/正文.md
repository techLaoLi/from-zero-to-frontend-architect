# h1 到 h6 和 p 各表示什么

## 简单示例（H1、H2...H6、p）

以下是一个简单的 html 示例，基本结构不变，body 中新增了 h系列标签和p标签，UTF-8 保存，刷新。Mac 用 `Cmd + R`，Windows 用 `F5`。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>标题和段落</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <p>这是一门给零基础的人准备的课程。</p>

  <h2>课程里有什么</h2>
  <p>先学会用标题和段落把一页内容分清楚。</p>

  <h3>标题</h3>
  <p>标题用来标出每一节的名字。</p>

  <h4>一级到六级</h4>
  <p>数字越小，这一级越高。</p>

  <h5>页面上的样子</h5>
  <p>更大、更粗，是浏览器附带的。</p>

  <h6>不要用它选字号</h6>
  <p>想改大小和颜色，以后用 CSS。</p>
</body>
</html>
```

页面上会出现六行标题和六段话。标题一行比一行小，但都比正文粗。段和段之间有一块空隙。标签页上仍是「标题和段落」，那是 `title`，不是 `h1`。

## 标签介绍（概念和特征）

`h1` 到 `h6` 是标题，数字是级别：`h1` 最高，`h6` 最低。`p` 是一段话。级别和「这是不是一段」，是这两个标签要表达的意思。字号和空隙是浏览器看见它们之后附带画上的。

| 标签 | 表示什么 | 这一页怎么用 |
|---|---|---|
| `h1` | 全页最高的标题 | 只写一个，作为整页的题目 |
| `h2` | `h1` 下面的一节 | 紧接在 `h1` 之后 |
| `h3` | `h2` 下面的一小节 | 紧接在某个 `h2` 之后 |
| `h4` 到 `h6` | 再往下的层级 | 中间不跳号 |
| `p` | 一段完整的话 | 下一段另写一个 `p` |

### `h1` 到 `h6`

- 字号：数字小，级别高，默认字号大，`h1` 的字号约为正文的 2 倍，然后逐级变小，到 `h6` 约为 0.67 倍。
- 样式：默认样式就是标题加粗。
- 一般而言，一个网页的只保留一个`h1`，当作整页的标题。往下按顺序用 `h2`、`h3`，中间不跳号。`h1` 后面直接写 `h3`，页面不会报错，`h3` 也不会自动变成二级。
- 一个网页html，如果写两个 `h1`，同样不会报错，但这页就有了两个最高标题。（不符合正常规范，但是语法规则是允许的）
- `h1`和 `head` 里的 `title` 区别，他们是两个元素，`h1`表示页面正文给人看的标题是什么，`title`表示标签页展示的标题是什么。

### `p`

一段完整的话放进一个 `p`，下一段再写一个 `p`。每个 `p` 自己占一块，上下有默认空隙，规范建议大约是一行字的高度。你看见的段间距来自这里，不是来自源码里多按的回车。

`p` 里面不再套 `p`。写成 `<p>第一句<p>第二句</p>` 时，浏览器会在第二个 `<p>` 之前结束第一段，页面上仍是两段，结构已经不是你写的那一个 `p`。

源码里的空格和回车到了页面上会怎么合并，同一段里怎么换行，是后面的课程「HTML的br和hr标签」。

## 要点总结

1. `h1` 到 `h6` 的数字是标题级别，不是字号。数字越小，级别越高。
2. 一页一个 `h1`。往下写 `h2`、`h3`，中间不跳号。写错级别页面仍会显示，浏览器不会替你改数字。
3. 一段完整的话用一个 `p`，下一段另起一个 `p`。段与段之间的空隙是浏览器的默认样式。
4. 更大、更粗是浏览器附带的样子。要改字号或颜色，用 CSS，不靠换标题级别。
5. 页面上的 `h1` 和标签页上的 `title` 是两处字。改一边，另一边不会跟着变。
