# blockquote 和 q 有什么区别？引用内容怎么标

**`blockquote` 标记整段引自别处的原文，自己占一块；`q` 标记句子中间的一句短引语，留在行内。** 两者都只用于引用别人写的内容，浏览器对它们的默认处理不一样：`blockquote` 左右留白，`q` 自动加引号。

本文解决一个具体问题：引用别人的话时，整段搬过来和句子里夹一句，分别用什么标签，出处写在哪里。

## blockquote 和 q 写出来的引用

把下面存成 `index.html`，用浏览器打开。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>引用</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <p>课程说明里有一句：</p>
  <blockquote cite="https://example.com/course">
    <p>先把结构写对，再谈好看。</p>
  </blockquote>
  <p>出自课程说明。</p>
  <p>老师接着说：<q>标题先写，段落跟在后面。</q></p>
</body>
</html>
```

这段代码演示的是两种引用的排版差别。跑完你会看到：「先把结构写对，再谈好看。」单独占一块，浏览器通常把它左右收进一截；「标题先写，段落跟在后面。」仍留在最后一段里面，前后多了一对引号——引号是浏览器加上的，`q` 中间本身没有引号。

`cite` 里的 `https://example.com/course` 不会出现在页面上。要让读者看见出处，写成 `blockquote` 后面的那个 `p`。

## blockquote 和 q 的概念和区别

| 对比项 | `blockquote` | `q` |
|---|---|---|
| 引多少 | 单独成块的一段或几段 | 句子里的一句 |
| 占不占一块 | 占一块 | 留在行内 |
| 浏览器通常 | 左右留出空白 | 自动加上引号 |
| 出处写在哪 | 标签外面的文字；网址可放 `cite` | 同一句里写清；网址可放 `cite` |

**`blockquote` 表示整段引自别处。** 里面的一段话仍用 `p`。谁说的、出自哪，写在 `blockquote` 的外面——出处不是原话的一部分，示例里「出自课程说明。」是后一个 `p`。

**`q` 表示句子里的短引语。** 不自己另起一块。这一页写了 `lang="zh-CN"`，打开后看你这个浏览器给出的那一对。`q` 里面不要再打引号，否则会看到两层。

`cite` 是 `blockquote` 和 `q` 都可以写的属性，值是出处的网址，浏览器默认不显示它。给人看的那句出处，仍要写成页面上的文字。

这两个标签只用于别处引来的原文。想让自己写的段落缩进，以后用样式。

## 要点总结：引用标签怎么选

1. 整段原话用 `blockquote`，里面的段落仍写 `p`。短引语用 `q`，留在句子里。
2. 谁说的，写在 `blockquote` 外面。`cite` 里的网址页面上看不见。
3. `q` 的引号由浏览器加上，里面不要再打一对。
4. 自己写的句子不用这两个标签。想缩进，以后用样式。
