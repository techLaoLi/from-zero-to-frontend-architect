# table 标签怎么写？tr、th、td 一次讲清

**`table` 是 HTML 里放行列对齐数据的标签，`tr` 是一行，`th` 是表头单元格，`td` 是数据单元格。** 四层是一套固定套法：`table` 包住所有 `tr`，每个 `tr` 里放若干 `th` 或 `td`。

本文解决一个具体问题：一张带表头的数据表，HTML 里怎么一层层写出来。

## table、tr、th、td 写出来的一张表

把下面存成 `index.html`，用浏览器打开。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>课程表</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <table>
    <tr>
      <th>阶段</th>
      <th>内容</th>
      <th>篇数</th>
    </tr>
    <tr>
      <td>S0</td>
      <td>语言与浏览器基础</td>
      <td>99</td>
    </tr>
    <tr>
      <td>S1</td>
      <td>框架与组件化</td>
      <td>28</td>
    </tr>
  </table>
</body>
</html>
```

这段代码演示的是一张三列三行的表怎么写。跑完你会看到：第一行是表头，浏览器默认加粗并居中；下面两行是数据，左对齐。表格四周有细线，每一格的大小跟着里面的内容走。

`<table>` 里直接放的是 `<tr>`，不是 `<td>`。少了 `tr` 这一层，浏览器会把表格渲染得不对。

## table 里面有哪些标签

| 标签 | 写在哪一层 | 表示什么 | 默认样式 |
|---|---|---|---|
| `table` | 最外层 | 整张表 | 四周有边线 |
| `tr` | `table` 里 | 一行 | 无 |
| `th` | `tr` 里 | 表头单元格 | 加粗、居中 |
| `td` | `tr` 里 | 数据单元格 | 不加粗、左对齐 |

**`tr` 是行。** 每行必须写在 `table` 里面，一行一个 `tr`。

**`th` 和 `td` 都是格子，区别在于角色。** `th` 是这一列或这一行的标题，说明下面是什么；`td` 是具体的数据。浏览器给 `th` 加粗并居中，给 `td` 左对齐，这个区别是浏览器默认给的。

格子里面还能放别的标签，比如一段说明、一个链接、一个列表。写成 `<td><p>说明文字</p></td>` 是允许的。

## thead、tbody、caption 各装什么

三个可选标签，把表里不同的部分分开标记。

| 标签 | 装什么 | 放在哪一层 |
|---|---|---|
| `caption` | 一句话说明这张表在讲什么 | `table` 里，`tr` 外面 |
| `thead` | 表头那几行 | `table` 里 |
| `tbody` | 数据那些行 | `table` 里 |

`caption` 写在 `table` 里、所有 `tr` 的外面。它是一句说明，比如「各阶段的学习内容」。浏览器会把它显示在表格上方。

`thead` 装表头行，`tbody` 装数据行。这两个不是必需的，直接把 `tr` 写在 `table` 里，浏览器也能正常渲染。加上它们的好处是结构清楚，以后要用样式区分表头和数据时更方便。

## 要点总结：表格的四层结构

1. `table` 包住整张表，`tr` 是一行，行里才是 `th` 或 `td`。三层不能省。
2. `th` 是表头，浏览器默认加粗居中；`td` 是数据，左对齐。
3. `caption` 装一句话说明，`thead` 装表头行，`tbody` 装数据行，都写在 `table` 里。
4. 页面左右分栏不要用表格来做。表格只放行列对齐的数据。
