# a 标签怎么链到别处和本页

## 简单示例（a、href、文件名、../、/、https://、#id、target）

`a` 加上 `href`，才是一个能点的链接。先准备两个文件，放在同一个文件夹里。

`note.html`：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>课程大纲</title>
</head>
<body>
  <h1>课程大纲</h1>
  <p><a href="index.html">返回课程介绍</a></p>
</body>
</html>
```

`index.html`：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>链接</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <p><a href="note.html">课程大纲</a></p>
  <p><a href="https://developer.mozilla.org/zh-CN/docs/Web/HTML/Element/a" target="_blank" rel="noopener">MDN 上的 a 标签</a></p>
  <p><a href="#practice">跳到本页练习</a></p>
  <h2 id="practice">练习</h2>
  <p>这一节在页面下方。点上面的链接会滚到这里。</p>
</body>
</html>
```

两个文件都用 UTF-8 保存。用浏览器打开 `index.html`。点「课程大纲」会打开旁边的 `note.html`。点「MDN 上的 a 标签」会新开一个标签页，进入 MDN。点「跳到本页练习」会滚到 `id="practice"` 的那一节。

链接上的字写成目的地。「课程大纲」能看出点开是什么。不要写成「点击这里」。

## 标签介绍（概念和特征）

### 链接本身

`<a href="地址">链接文字</a>`。`href` 里是点开以后去的地址。没有 `href` 的 `a` 只是包住几个字，点不开。

在新标签页打开时，写成 `target="_blank"`，并在旁边加上 `rel="noopener"`。`noopener` 让新页面拿不到原来这一页的控制权。两个属性都写在开始标签里。

### 地址怎么写

地址按文件和当前页的位置来拼。

| 写法 | 去哪里 |
|---|---|
| `note.html` | 和当前文件同一个文件夹 |
| `images/cover.png` | 当前文件夹下的 `images` 子文件夹 |
| `../note.html` | 上一级文件夹 |
| `/note.html` | 网站上的根目录。本地双击打开时，`/` 是磁盘根目录，不是你的项目文件夹 |
| `https://...` | 另一台服务器上的完整地址 |

这一阶段练习，用文件名、`images/...` 和 `../`。页面还没放到网站上时，不要用 `/` 开头去找项目里的文件。

点开后是找不到的页面时，先看地址栏里最后拼出来的那一串。把 `href` 改成 `notes.html`（多一个 s），再点一次。「课程大纲」会打不开，地址栏停在 `notes.html`。文件实际叫 `note.html`。改回正确的文件名。

### 跳到本页某一段

先给要到达的那个元素一个 `id`，例如 `<h2 id="practice">`。链接写成 `href="#practice"`。`#` 后面的名字必须和页面上某个 `id` 完全一致，包括大小写。

同一个 `id`，这一页只能有一个。写了两个 `id="practice"`，浏览器只会按它找到的那一个来滚，你指定不了要去哪一个。名字里不要有空格。

`#` 后面的名字对不上任何 `id` 时，页面停在原地，或只回到顶部。对照地址栏里 `#` 后面的那一段和源码里的 `id`。

`id` 也可以加在 `h1`、`p`、`div` 等元素上。这一篇先加在要跳到的标题上。

## 要点总结

1. `a` 加上 `href` 才是能点的链接。链接文字写成目的地，例如「课程大纲」。
2. 同一文件夹写文件名，子文件夹写 `images/cover.png`，上一级写 `../`。`https://` 是另一台服务器。
3. 新标签页打开时，`target="_blank"` 旁边写上 `rel="noopener"`。
4. 页内跳转先给目标一个唯一的 `id`，链接写成 `href="#这个id"`。对不上就到不了。
5. 点开找不到时，先读地址栏里最后拼出来的地址。
