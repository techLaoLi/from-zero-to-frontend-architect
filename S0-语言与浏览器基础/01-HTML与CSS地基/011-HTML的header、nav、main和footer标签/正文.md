# header、nav、main、footer 四个标签各管哪一块？

**`header`、`nav`、`main`、`footer` 是 HTML 的页面结构标签，分别标记页头、主要导航链接、整页正文和页脚。** 相比 `div`，它们多了一层含义：浏览器和搜索引擎能看出这一块在页面里扮演什么角色。

本文解决一个具体问题：写一张完整页面时，整页该分成哪几块，每一块用哪个标签。

## header、nav、main、footer 写出来的整页结构

把下面存成 `index.html`，用浏览器打开。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>页头和页脚</title>
</head>
<body>
  <header>
    <p>前端课程</p>
    <nav>
      <ul>
        <li><a href="index.html">首页</a></li>
        <li><a href="outline.html">大纲</a></li>
      </ul>
    </nav>
  </header>
  <main>
    <h1>前端从零到架构师</h1>
    <p>这是一门给零基础的人准备的课程。</p>
  </main>
  <footer>
    <p>本页只讲结构。</p>
  </footer>
</body>
</html>
```

这段代码演示的是一张页面怎么分成四块。跑完你会看到：四块从上往下依次排开，「前端课程」和两条链接在最上面，标题和介绍在中间，最后一句在最下面。样子和用 `div` 包住时接近——自己占一块，没有特殊颜色。链接前面的圆点来自 `ul`。

`header`、`main`、`footer` 是平级的，都直接写在 `body` 里。`body` 不是只能装这四个，四块之外还能再放别的内容。

## 四个标签的概念和适用位置

| 标签 | 标记什么 | 这一页放什么 | 注意 |
|---|---|---|---|
| `header` | 页头 | 站点名字和导航 | 页面上看得见 |
| `nav` | 主要导航 | 去首页、去大纲的链接 | 只包主要导航 |
| `main` | 整页正文 | 标题 `h1` 和介绍 | 一页写一个 |
| `footer` | 页脚 | 收尾的那一句 | 写在源码最后 |

**`header` 是页头上先看见的内容。** 例如站点名字和导航。它写在 `body` 里面，读者看得见。

**`nav` 是一组主要的导航链接。** 用来去别的页，或去本页的某一段。链接本身仍用 `a`。页脚里的一行说明，不必再套 `nav`。

**`main` 是整页的正文。** 它和 `header`、`footer` 平级，直接放在 `body` 里，一页只写一个。不要放进 `header`、`nav` 或 `footer` 里面。放进去页面仍然会显示，但这一块就不再是整页的正文了。

**`footer` 是页脚。** 放收尾的信息，例如一句版权或说明。写在源码的最后，页面上就出现在最后。让它贴住窗口底部，以后用样式做。

## header 和 head 有什么区别

`head` 和 `header` 是两个不同的标签，只差一个字母。`head` 在正文之外，放字符集和标签页标题，页面上看不见；`header` 写在 `body` 里，是读者看得见的页头。

这一篇的示例里，`<head>` 中的 `<title>页头和页脚</title>` 是浏览器标签页上的那行字，不出现在页面上；`<header>` 里的「前端课程」是页面上的第一行文字。

## 要点总结：整页结构怎么搭

1. 整页四块用 `header`、`nav`、`main`、`footer` 标记，四个都写在 `body` 里。
2. `header` 是看得见的页头，`head` 不显示，两个不要混。
3. `main` 是正文，一页一个，和 `header`、`footer` 平级，不要放进它们里面。
4. `nav` 只包主要导航。说不出角色、只是想包住一块，继续用 `div`。
