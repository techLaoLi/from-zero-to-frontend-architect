# header、nav、footer 各管哪一块

## 简单示例（header、nav、main、footer）

整页分成页头、导航、正文、页脚。这四块各用自己的标签。

把下面存成 `index.html`，用浏览器打开。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>页头和页脚</title>
</head>
<body>
  <header>
    <p>前端课程</p>
    <nav>
      <ul>
        <li><a href="index.html">首页</a></li>
        <li><a href="outline.html">大纲</a></li>
      </ul>
    </nav>
  </header>
  <main>
    <h1>前端从零到架构师</h1>
    <p>这是一门给零基础的人准备的课程。</p>
  </main>
  <footer>
    <p>本页只讲结构。</p>
  </footer>
</body>
</html>
```

四块上下排开。「前端课程」和两条链接在最上面，标题和介绍在中间，最后一句在最下面。样子和用 `div` 包住时接近：自己占一块，没有特殊颜色。链接前面的圆点来自 `ul`。

「首页」链回当前这个文件。「大纲」那一页还没写，点开会打不开。这一篇先看每块包住什么。

## 标签介绍（概念和特征）

这四个标签都说出一块内容是什么角色。`div` 只负责包住，不表示页头或正文。

`header` 是页头，放这一页开头先看见的内容，例如站点名字和导航。它和 `head` 不是同一个标签。`head` 在正文之外，放字符集和标签页标题，页面上看不见。`header` 写在 `body` 里，读者看得见。

`nav` 是一组主要的导航链接，用来去别的页，或去本页的某一段。链接仍用 `a`。页脚里的一行说明，不必再套 `nav`。

`main` 是这一页的正文。它和 `header`、`footer` 平级，直接放在 `body` 里。一页写一个。不要放进 `header`、`nav` 或 `footer`。放进去页面仍会显示，但这块就不再是整页的正文。

`footer` 是页脚，放收尾的信息，例如一句版权或说明。写在源码的最后，页面上就出现在最后。让它贴住窗口底部，以后用样式做。

| 标签 | 表示什么 | 这一页放什么 |
|---|---|---|
| `header` | 页头 | 站点名字和导航 |
| `nav` | 主要导航 | 去首页、去大纲的链接 |
| `main` | 正文 | 标题 `h1` 和介绍 |
| `footer` | 页脚 | 收尾的那一句 |

只是包住一块、又说不出角色时，继续用 `div`。

## 要点总结

1. `header` 是页面上看得见的页头。`head` 不显示，两个标签不要混。
2. `nav` 只包主要导航。页脚里的一行说明，不必再套 `nav`。
3. `main` 是正文，一页一个，和 `header`、`footer` 平级。不要放进 `header`、`nav`、`footer` 里面。
4. `footer` 写在源码最后，就出现在页面最后。贴住窗口底部以后再做。
