# HTML 实体：把 < 和 & 显示出来

## 简单示例（&lt;、&gt;、&amp;）

小于号、大于号和 `&` 不能在正文里直接打出来，那在html中，如何显示呢？请看下面这个示例：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>把尖括号显示出来</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <p>段落标签写成 &lt;p&gt;，页面上才能看见尖括号。</p>
  <p>AND 这个词有时写成 A&amp;B。</p>
</body>
</html>
```

第一段显示的是：段落标签写成 `<p>`。第二段显示的是 `A&B`。

在html的展示中，部分字符，如 `<`、`>`、`&`，不能直接在html里打出来。需要用特殊的字符来显示，就叫`实体字符`

## 标签介绍（概念和特征）

正文里的 `<` 是标签的开头。浏览器从这里开始认一个标签，直到 `>`。所以要显示小于号、大于号，必须换成实体字符：一种以 `&` 开头、以分号结尾的写法。

| 要显示的字符 | 写成 |
|---|---|
| `<` | `&lt;` |
| `>` | `&gt;` |
| `&` | `&amp;` |

`lt` 是 less than，`gt` 是 greater than，`amp` 是 ampersand。 

`&` 本身是实体的开头。正文里要显示 `&` 这个符号，写成 `&amp;`。否则它后面的字母会被拿去匹配一个实体名字。

普通空格、中文、中文标点直接打。逗号、句号、冒号、书名号都不需要换成实体。上一篇说过，连续的普通空格会被收成一个，那是空格的规则，不是因为空格必须转义。

日常查完整的实体名单，用 MDN 的「HTML 中的实体」页面（`developer.mozilla.org`）。这一篇先记住这三对。

## 要点总结

1. 直接写 `<`，浏览器会把它当成标签的开头。
2. 小于号写成 `&lt;`，大于号写成 `&gt;`，`&` 本身写成 `&amp;`。三对都带分号。
3. 普通空格、中文和中文标点直接打，不必换成实体。
