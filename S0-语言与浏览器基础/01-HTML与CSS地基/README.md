## 文章清单

### 页面里先有内容

先让浏览器打开一份文件，里面有标题、段落、链接和图片。颜色、字号、页头页脚，这一组先不动。

- [x] HTML概述
  - 整体说明
  - HTML、CSS、JavaScript分别都是干什么的？
  - HTML概念和定义
  - 验收标准
- [x] 初识HTML
  - 一个最简单的HTML片段
  - HTML每个片段的说明和介绍
  - 验收标准
- [ ] 标题和段落
  - `h1` 到 `h6` 的数字表示谁是上级，不表示字号
  - 一页一个 `h1`，往下写 `h2`、`h3`，中间不跳号
  - 一段完整的话放进一个 `p`，下一段再写一个 `p`
  - 标题默认更大、段与段之间默认有空隙，这是浏览器带的
- [ ] 标出哪几个字重要
  - 内容上重要，用 `strong`，浏览器通常显示成粗体
  - 读的时候要重读，用 `em`，浏览器通常显示成斜体
  - `b` 和 `i` 只是粗和斜，不表示这段更重要
  - 要改颜色，或只要「粗一点」，不靠换标签
- [ ] 空格、换行和横线
  - 源码里连着按的空格和回车，页面上多半只剩一个空格
  - 同一段里想换一行，用 `br`；这仍是这一段，不是新的一段
  - `hr` 表示话题换了，页面上是一条横线
  - 段与段的空隙靠两个 `p`，不靠多按几次回车
  - `&nbsp;` 是一个不换行的空格，不能用来把两块内容推开
- [ ] 把尖括号显示出来
  - 直接写小于号，浏览器会把它当成标签的开头
  - 要显示小于号、大于号，写成 `&lt;`、`&gt;`
  - 要显示 `&` 这个符号本身，写成 `&amp;`
  - 普通空格、中文和中文标点，直接打进去
- [ ] 链接
  - `a` 加上 `href`，才是一个能点的链接
  - `href` 里写点开以后去的地址
  - 链接上的字写成目的地，例如「课程大纲」，不写「点击这里」
  - 在新标签页打开时，`target="_blank"` 旁边加上 `rel="noopener"`
- [ ] 链接地址怎么写
  - 同一个文件夹里的文件，直接写文件名
  - 进子文件夹写 `images/cover.png`，回上一层写 `../`
  - 以 `/` 开头，从网站根目录算起
  - 以 `https://` 开头，是另一台服务器上的地址
  - 点开是找不到的页面时，先看地址栏里最后拼出来的那一串
- [ ] 点一下，跳到本页某一段
  - 先给要到达的那个元素一个 `id`
  - 链接写成 `href="#这个id"`，点了就滚到那里
  - 同一个 `id`，这一页只能有一个
  - `#` 后面的名字，必须和页面上某个 `id` 对得上
- [ ] 插入图片
  - `img` 的 `src` 写图片地址，写法和链接地址相同
  - `alt` 写出这张图在告诉读者什么
  - 纯装饰、旁边文字已经说清的图，`alt` 留空
  - 图加载失败时，读者看到的就是 `alt` 里的字
  - 这一篇先把图放出来，宽和高先不写死
- [ ] 列表
  - 没有先后的一组，用 `ul`；步骤或名次，用 `ol`
  - 每一条都是 `li`，放在 `ul` 或 `ol` 里面
  - 某一条下面还可以再套一层列表
  - 圆点和数字是浏览器默认画的
- [ ] div 和 span
  - `div` 自己占一块，用来包住一组内容
  - `span` 用在一句话里面，包住其中几个字
  - 两个标签本身不表示「这是标题」或「这是导航」
  - 已经有更合适的标签时，用那个标签
  - 后面写样式时，靠 `class` 区分这些普通容器

### 给每块内容一个准确的标签

页头、文章、引用、代码、图的说明，各有自己的标签。表格和能填写的表单还在后面。

- [ ] 页头、导航、正文和页脚
  - `header` 是一块内容的开头，可以是整页的，也可以是一篇文章的
  - `footer` 放收尾信息，例如版权、相关链接
  - `nav` 只包住一组导航链接
  - `main` 是这页的正文，一页只放一个
  - 整页最外层，用这几个标签分出区域
- [ ] 一篇文章，和其中的一节
  - `article` 包住一块可以单独拿走、单独读完的内容
  - `section` 是同一篇里的一节，里面要有自己的标题
  - 只是为了包一层、里面没有标题，先用 `div`
  - 拿不准时问一句：这块能不能单独发成一篇
- [ ] 引用别人的话
  - 单独成段的引用，用 `blockquote`
  - 嵌在句子里的短引用，用 `q`
  - 引用和自己写的正文要能分开
  - 这句话是谁说的，用文字写在旁边
- [ ] 在页面里放一段代码
  - 一句话里出现的代码名，用 `code`
  - 要保留换行和空格的整段代码，用 `pre` 包住 `code`
  - 代码里的小于号仍然写成 `&lt;`，不然会被当成标签
  - 等宽字体是浏览器对 `code` 的默认样子
- [ ] 图片和它的说明
  - `figure` 把图和它的说明放在一起
  - `figcaption` 是给读者看的那句说明
  - `alt` 是图没加载出来时的替代文字，和说明不是同一句
  - `figure` 里也可以是一段代码，不限于图片

### 表格

表格用来放行列对齐的数据。页面左右分栏，不用表格来做。

- [ ] 一张数据表
  - `table` 里面是一行行、一列列的数据
  - `tr` 是一行，`th` 是表头，`td` 是格子里的数据
  - `thead` 放表头那几行，`tbody` 放数据
  - `caption` 用一句话说明这张表在说什么
- [ ] 合并单元格
  - `colspan="2"` 让这个格子向右占两列
  - `rowspan="2"` 让这个格子向下占两行
  - 被占掉的位置，不要再写一个空的 `td`
  - 先在纸上把格子画出来，再对着格子写标签

### 表单

做一张能填写、能点提交的表。没有服务器。提交之后，看地址栏里 `?` 后面多了哪些字段。

- [ ] 用 form 把输入收成一组
  - `form` 表示里面这些输入是一起提交的
  - `action` 写提交到哪里，`method` 先用 `get`
  - 用 `get` 提交后，字段出现在地址栏 `?` 后面
  - 输入框写在这个 `form` 里面，才会被一起提交
- [ ] 单行文本框，和旁边的文字
  - 单行文字用 `input type="text"`
  - `label` 的 `for` 写成输入框的 `id`，点文字也能把光标放进去
  - `placeholder` 是框里的示例，框外面仍要有 `label`
  - `name` 是提交时用的字段名，会出现在地址栏里
- [ ] 密码框、邮箱框和多行文字
  - 密码用 `type="password"`，输入时页面上不显示原文
  - 邮箱用 `type="email"`，数字用 `type="number"`
  - 要写好几行，用 `textarea`
  - 空不空、像不像邮箱，放到后面的检查那一篇
- [ ] 单选和多选
  - 同一组单选框用同一个 `name`，选了一个，另一个会取消
  - 同一组多选框也用同一个 `name`，但可以同时选多项
  - 每个选项有自己的 `value`，提交上去的是 `value`，不是旁边的文字
  - 选项旁边的字，用 `label` 连到对应的 `input`
- [ ] 下拉框
  - `select` 是下拉框，里面每个 `option` 是一个选项
  - 提交时带上选中那一项的 `value`
  - 给某一项加上 `selected`，打开页面时就选中它
  - 只能选一个、选项又比较多，用下拉框，不用一长串单选
- [ ] 提交按钮
  - `button type="submit"` 会提交它所在的表单
  - `type="button"` 只是一个按钮，点了不会提交
  - `type="reset"` 会把已填的内容清掉，普通表单不要用它
  - 按钮就用 `button`，不要用一块 `div` 来假装
- [ ] 提交前，浏览器会做的检查
  - 加上 `required`，这个框空着就不能提交
  - `type="email"` 会看内容像不像一个邮箱
  - `min`、`max` 限制数字范围，`maxlength` 限制能输入多少字
  - 没通过时，弹出的是浏览器自己的提示
- [ ] 给一组输入加个小标题
  - `fieldset` 把相关的几个框放在一起
  - `legend` 是这一组的标题，例如「联系方式」
  - 四周的框线是浏览器默认画的，表示这些字段是一组
  - 这一组仍属于原来的那个 `form`
- [ ] 不能改的两种情况
  - `disabled`：不能改，提交时这个字段不会出现
  - `readonly`：不能改，提交时这个字段仍会带上
  - 先问两句：现在允不允许改；改不了的值，还要不要提交
  - 先在文本框上区分这两个属性

### 声音、视频和标签页

让页面能播放，并写好标签页上能看见的小图标、标题和一段简介。

- [ ] 播放声音和视频
  - `video` 放视频，`audio` 放声音
  - 加上 `controls`，才会出现浏览器自带的播放条
  - 同一种内容有多种格式时，用多个 `source`，浏览器选它能播的那个
  - `autoplay` 经常被浏览器拦住，不要假设一打开就会出声
- [ ] 标签页上的小图标
  - `head` 里写 `link rel="icon"`，指向一张 `.ico` 或 `.png`
  - 这张图出现在浏览器标签页上
  - 地址写法和前面的文件路径一样
  - 没写的时候，浏览器还会自己去要一次 `/favicon.ico`
- [ ] 标签页标题，和一段简介
  - `title` 是标签页上的字，也常被当作搜索结果里的标题
  - `meta name="description"` 是准备给搜索结果看的那段摘要
  - 搜索引擎不一定原样采用你写的摘要
  - 正文里仍是一个说得清的 `h1`

### 样式写在哪，写给谁

从这里开始，外观写在单独的 `.css` 文件里。HTML 继续只放内容。

- [ ] 样式放进 css 文件
  - HTML 管这页有什么，CSS 管它们长什么样
  - 样式可以写在标签上、写在 `head` 里的 `style` 中，或写在外部文件里
  - 本专栏后面的样式，都写在外部文件里
  - `head` 里用 `link rel="stylesheet"` 把文件接上
- [ ] 一条样式长什么样
  - 选择器写在前面，决定这组样式作用到谁
  - 花括号里面，每一条是 `属性: 值;`
  - 一个选择器后面可以写好几条
  - `/* 注释 */` 只给人看，不会出现在页面上
- [ ] 用 class 给一组元素加样式
  - 给元素加上 `class`，同一类可以共用一套样式
  - `id` 在一页里只给一个元素
  - CSS 里用 `.类名` 选中 class，用 `#id` 选中 id
  - 要复用的样式写在 class 上；`id` 留给本页跳转，和表单标签的 `for`
  - `a.button` 表示：必须是链接，并且带有这个 class
- [ ] 选中某一种标签
  - 写 `p`，就会选中页面上所有段落
  - 用逗号把多个选择器写在一起，它们共用同一套声明
  - 选择器太宽，会改到没打算改的元素
  - 先只改一小块里的一种元素，看清范围再放开
- [ ] 选中某一块里面的元素
  - `nav a` 中间一个空格，选中导航里面任意一层的链接
  - `nav > a` 只选中导航的下一层，更深的选不中
  - 选择器写得越具体，管到的元素越少
  - 要改「这一块里的链接」，先从 `nav a` 这种写法开始
- [ ] 鼠标放上去，以及键盘选中时
  - `:hover` 是指针放在元素上
  - `:focus` 是这个元素正被操作，用键盘也能到
  - 写在选择器后面，例如 `a:hover`、`input:focus`
  - 链接、按钮、输入框，都要能看出焦点在哪
  - 去掉浏览器自带的焦点框之后，要另外给一个看得见的变化
- [ ] 两条样式冲突时，听谁的
  - 写在元素 `style` 上的，强于 `#id`
  - `#id` 强于 `.class`，`.class` 强于只写标签名
  - 强度一样时，样式表里后写的那条生效
  - 接了多个 css 文件时，后出现的 `link` 盖住先出现的
  - 想盖住一条旧样式，把选择器写准，不要把同一句复制很多遍
- [ ] 选择器的强弱怎么数
  - 先数有几个 `id`，多的赢
  - `id` 一样多，再数 class 和 `:hover` 这种伪类
  - 再比标签名有几个
  - `!important` 会跳过这套比较
  - 先把选择器写清楚，页面里先不写 `!important`
- [ ] 颜色和字体会不会传给里面
  - 颜色、字号、字体，写在外层，里面的元素会跟着用
  - 外边距、内边距、边框、背景，不会跟着传
  - 里面的元素自己写了同名属性，就用它自己的
  - 一整块文字要同一个颜色，写在包住它们的元素上

### 字和颜色

先把字的颜色、大小、行距定下来。盒子的宽高和边距，是下一组。

- [ ] 颜色的三种写法
  - 颜色名，例如 `black`
  - 十六进制，例如 `#333333`
  - `rgb(51, 51, 51)`，红、绿、蓝各从 0 到 255
  - 同一张页面里，同一种颜色用同一种写法
- [ ] 字号、字体和粗细
  - `font-size` 决定字有多大
  - `font-family` 按顺序写备用字体，最后写一个通用的，例如 `sans-serif`
  - 常规是 `font-weight: 400`，粗体是 `700`
  - 整页的字先写在 `body` 上，标题再单独改
- [ ] 行高，和文字靠哪边
  - `line-height: 1.6` 这种不带单位的数字，表示字号的 1.6 倍
  - `text-align` 让文字在盒子里靠左、居中或靠右
  - `text-decoration` 用来加下划线，或把链接的下划线去掉
  - 一段字读着挤，先把行高调大

### 盒子的边距、边框和背景

每个元素都是一个盒子。先看清从里到外的四层，再谈背景和圆角。元素横着排、竖着排，是下一组的事。

- [ ] 内容、内边距、边框、外边距
  - 从里到外：内容、`padding`、`border`、`margin`
  - `padding` 是内容和边框之间的空白
  - `margin` 是这个盒子和旁边盒子之间的空白
  - 在浏览器的元素面板里，可以点开这四层看
- [ ] width 到底包住哪几层
  - 默认时，`width` 只算内容，`padding` 和边框加在这个宽度外面
  - 写上 `box-sizing: border-box` 后，`width` 把内容、内边距、边框算在一起
  - 页面开头先让元素都用 `border-box`
  - 盒子比你写的宽度更宽时，先看是不是还在用默认算法
- [ ] 上下外边距会粘成一段
  - 上下挨着的两个块，垂直方向的 `margin` 会合成一段，取较大的那个
  - 父元素和第一个子元素贴在一起、中间没有内边距或边框隔开时，子元素的上外边距会跑到父元素外面
  - 左右的 `margin` 不会这样合并
  - 间距比预想少一截，先看是不是被合并了
- [ ] 背景色铺在哪一层
  - `background-color` 铺在内容和内边距上
  - 默认不铺进外边距，所以外边距那一圈是透明的
  - 背景在文字和子元素的下面
  - 想要一整块底色，把颜色写在包住内容的盒子上
- [ ] 用一张图做背景
  - `background-image` 用 `url()` 指向那张图
  - `cover` 是铺满，多出来的裁掉；`contain` 是整张都看见，可能留空
  - `background-position` 决定图靠哪一边，或放在中间
  - 这张图是装饰；读者必须知道的信息，仍写在 HTML 里
- [ ] 边框和圆角
  - `border` 按宽度、线的样式、颜色来写，例如 `1px solid #ddd`
  - 可以只给一边，例如 `border-bottom`
  - `border-radius` 让角变圆
  - 圆角加到高度的一半，会变成胶囊形

### 元素默认怎么排队

先看懂浏览器本来怎么把盒子一个个摆下去。要用 Flex 或 Grid 改摆法，放到后面。

- [ ] 独占一行，还是挤在同一行
  - `div`、`p` 这类默认自己占一行，可以设宽度和高度
  - `span`、`a` 默认挤在一行文字里，设宽高通常没效果
  - 这是元素自己的默认身份
  - `display` 可以改掉这个身份
- [ ] 留在一行里，又能设宽高
  - `display: inline-block` 仍跟文字排在一行，同时可以设宽高
  - 适合一小排按钮或标签
  - 两个元素之间多出来的空隙，常常是 HTML 里的换行造成的
  - 一整行要按比例分完，这种写法不够用
- [ ] 块往下排，字往右排
  - 块级盒子默认从上往下排
  - 一行里的文字从左往右排，排不下再换行
  - 还在这套排列里的盒子会占住位置，后面的让开
  - 用了定位，才能把盒子从这套排列里拿出去
- [ ] 让文字绕着图片走
  - `float` 最初就是为了让文字绕着图片走
  - 浮动之后，它不再撑起父元素的高度
  - 老页面会用它做左右两列
  - 新写的分栏不用它；要能看懂别人页面里的浮动
- [ ] 浏览器自带的边距和圆点
  - `body` 四周自带一圈外边距，内容会离窗口有一条缝
  - 链接自带颜色和下划线
  - 列表自带圆点，还有一截左侧缩进
  - 只改这一页用到的，不要一次把所有标签的默认样子清光

### 用 Flex 排成一行或一列

Flex 管一个方向：排成一行，或排成一列。行和列要同时设计，用后面的 Grid。

- [ ] 让子元素排成一行
  - `display: flex` 写在父元素上
  - 参加排列的，只是它的直接子元素
  - 默认从左排到右
  - 它管的是这一行怎么分，不管二维的格子
- [ ] 改成竖排，或排满就换行
  - `flex-direction: column` 改成从上往下排
  - 方向一变，哪边算「开头」跟着变
  - `flex-wrap: wrap` 允许这一行排满后换到下一行
  - 不换行时，项目会被挤在同一行里
- [ ] 这一行靠左、居中，还是两端分开
  - 沿排列方向多出来的空白，用 `justify-content` 来分
  - 横着排时，它可以让整组靠左、居中或靠右
  - `space-between` 让第一项贴左、最后一项贴右，中间的空隙均分
  - 它移动的是位置，不改变每一项自己的宽高
- [ ] 项在上下方向靠哪
  - 横着排时，上下这个方向用 `align-items`
  - 可以靠上、居中、靠下，或拉成一样高
  - 默认 `stretch`，项目会被拉到和这一行一样高
  - 只改其中一项，在那一项上写 `align-self`
- [ ] 换成多行之后，行与行怎么分
  - `align-content` 只在已经换行、出现多行时才看得到
  - 它分的是行与行之间的空白
  - 每一行里面各项怎么对齐，仍看 `align-items`
  - 只有一行时，改它没有变化
- [ ] 多出来的空白分给谁
  - `flex-grow` 默认是 `0`，不分多余的空白
  - 写成 `1` 的项目，去分剩下的空间
  - 几项都写了，按数字的比例分
  - 这一行已经满了，写了也看不出差别
- [ ] 分空白之前，每一项先占多宽
  - `flex-basis` 是开始分配之前，项目先占的那段长度
  - 写成 `auto`、并且这项自己写了宽度时，就用那个宽度
  - 没写宽度，就按内容自己有多宽
  - 它是起点；最后显示出来的宽，还可能被放大或缩小
- [ ] 一行挤不下时，谁缩小
  - `flex-shrink` 默认会缩小
  - 写成 `0`，这项拒绝缩小
  - 几项都允许缩，就按比例让出空间
  - 字或图从盒子里溢出来，先看这项是不是被设成了不缩小
- [ ] 一行写完放大、缩小和基准
  - `flex` 是三个值的简写：放大、缩小、基准
  - `flex: 1` 是放大 1、缩小 1、基准 `0%`
  - `flex: auto` 是放大 1、缩小 1、基准 `auto`
  - `flex: none` 是不放大、不缩小、基准 `auto`
  - 写了简写，就以简写为准
- [ ] 项和项之间留一条缝
  - `gap` 只出现在项目和项目之间，不加在容器外圈
  - 写一个值，行距和列距相同
  - 写两个值，先是行距，后是列距
  - 换行之后，行与行之间也是这条缝
  - 间距用 `gap`，不要靠每一项的左右外边距去凑
- [ ] 改看到的顺序，不改阅读顺序
  - `order` 改变项目在这一行里谁先谁后
  - 默认都是 `0`，数字更小的排在前面
  - 读屏软件和 Tab 键，仍按 HTML 里的先后走
  - 文档里的顺序写反了，回到 HTML 里改
- [ ] 在盒子里水平垂直居中
  - 父元素写成 `display: flex`
  - `justify-content: center` 负责排列方向上居中
  - `align-items: center` 负责另一个方向上居中
  - 父元素在垂直方向要有高度，不然没有空档可居中
- [ ] 导航：左边商标，右边菜单
  - 用 `justify-content: space-between`，或给右边的菜单 `margin-left: auto`
  - 菜单自己再排成一行，项与项之间用 `gap`
  - 菜单里的每一项是链接
  - 这一篇只做宽屏幕上的一行
- [ ] 一排里每块一样宽
  - 每个项目写同一个 `flex` 值，按同一基准分宽度
  - 项目里面的标题和文字，仍从上往下排
  - 块与块的距离，用父元素的 `gap`
  - 这一篇固定为一行
- [ ] 内容少时，页脚仍在窗口底部
  - 整页改成从上往下的 flex，最小高度写成 `100vh`
  - 中间的内容区写 `flex: 1`，把多余的高度吃掉
  - 页脚不放大，就落在窗口底部
  - 内容超过一屏时，页脚跟在内容后面，不盖住内容

### 用 Grid 排成格子

要同时规定有几列、有几行时用 Grid。只是一行或一列的地方，仍用 Flex。

- [ ] 划出几列、几行
  - `display: grid` 写在父元素上
  - `grid-template-columns` 写有几列、每列多宽
  - `grid-template-rows` 写行
  - 子元素按 HTML 里的顺序，自动进到格子里
  - 格子之间的缝用 `gap`；外圈的空白用 `padding`
- [ ] 把剩下的宽度分成几份
  - `fr` 是先扣掉固定宽度之后，剩余空间里的一份
  - `1fr 1fr 1fr` 把剩余空间分成三等份
  - `repeat(3, 1fr)` 是同一句的简写
  - 和像素写在一起时，先扣掉像素，剩下的再按 `fr` 分
- [ ] 卡片有最小宽度，列数跟着变
  - `minmax(240px, 1fr)` 表示这一列最窄 240 像素，有空再拉宽
  - `repeat(auto-fit, minmax(240px, 1fr))` 按容器有多宽，决定放几列
  - 容器变窄，列数减少，卡片往下排
  - 一排卡片，先用这一个写法
- [ ] 一个格子跨两列
  - `grid-column: span 2` 向右占两列
  - `grid-row: span 2` 向下占两行
  - 被占住的格子，后面的项目会自动躲开
  - 不能跨过这一行已经没剩下的格子
- [ ] 用第几条线来指定位置
  - 竖线从左往右数，从 1 开始
  - `grid-column: 1 / 3` 是从第 1 条线到第 3 条线，中间是两列
  - 负数从右边往回数，`-1` 是最后一条线
  - `span` 说占几格，线号说从哪条线到哪条线
- [ ] 给页头、侧栏、内容起名字
  - `grid-template-areas` 用每一行一个字符串，画出谁在哪
  - 同一个名字占住的格子，必须连成一块矩形
  - 写 `.` 的格子空着
  - 子元素用 `grid-area` 填上那个名字
- [ ] 格子里面的内容靠哪边
  - `justify-items` 管水平方向，`align-items` 管竖直方向
  - 默认会把项目拉满它所在的格子
  - 这里管的是格子内部，和 Flex 里同名属性不是一回事
  - 只改一个项目，用 `justify-self` 和 `align-self`

### 脱离正常排队，以及谁盖住谁

把某个元素从默认的排队里拿出来，或让它在滚动时停住。再处理两个盒子重叠时，谁画在上面。

- [ ] 五种定位，各自相对谁
  - `static` 是默认，按原来的队排；这时 `z-index` 没用
  - `relative` 相对自己本来的位置挪一挪，原来的空位还留着
  - `absolute` 和 `fixed` 会离开这支队
  - `sticky` 在还没滚到那个位置之前，仍占着原来的位子
- [ ] 相对原来的位置挪一挪
  - `position: relative`，再配 `top`、`right`、`bottom`、`left`
  - 挪的距离，相对它本来要待的那个位置
  - 原来的空位还在，后面的兄弟不会挤过来填
  - 它也常常只给里面的绝对定位当参照，自己可以不挪
- [ ] 离开队伍，相对父元素来摆
  - `position: absolute` 不再把父元素撑高
  - 它去找最近的、定位不是 `static` 的祖先，相对那个祖先算位置
  - 祖先都没有定位，就相对整页来算
  - 子元素跑到了页面角落，先给包住它的父元素加上 `position: relative`
- [ ] 钉在浏览器窗口上
  - `position: fixed` 相对窗口；页面向下滚，它还停在屏幕的那个位置
  - 它离开队伍，原来的位置不保留
  - 顶栏钉住时，后面的内容要留出顶栏那么高，避免被挡住
  - 外层如果写了 `transform`，参照会变成那个外层；做固定顶栏时先不要加
- [ ] 滚到顶部就吸住
  - `position: sticky` 在还没滚到那条线时，仍占着文档里的位置
  - `top: 0` 表示离窗口顶部为 0 时吸住
  - 吸住之后，它跟着窗口走
  - 某个祖先的 `overflow` 不是 `visible` 时，吸顶常常会失效
- [ ] 重叠时，默认谁在上面
  - 都在正常排队里时，后写的兄弟画在先写的上面
  - 一个元素的背景，画在它自己的文字和子元素下面
  - 元素还是默认定位时，`z-index` 不生效
  - 要控制谁在上面，先给它一个不是 `static` 的定位
- [ ] z-index 只在同一层里比较
  - 比较的是已经定位的元素
  - 数字大的在上面，也可以写成负数
  - 比较只发生在同一个层叠上下文里面
  - 父元素自己成了一层时，子元素的数字不能伸到这一层外面去压别人
- [ ] 为什么 z-index 有时出不去
  - 父元素 `opacity` 小于 1，会自己成为一层
  - 父元素写了 `transform`，也会自己成为一层
  - Flex 或 Grid 里的一项，只要 `z-index` 不是 `auto`，也会自己成为一层
  - 子元素怎么也压不到外面时，先检查父元素有没有这三种情况

### 屏幕变窄、变宽

同一份页面，在手机和宽屏幕上都能读。先写窄的样子，屏幕够宽，再加样式。

- [ ] 让手机按真实宽度来排
  - 视口是浏览器里真正用来排这一页的区域
  - 没声明时，手机常常按大约 980px 来排，再把整页缩小
  - `head` 里加上 viewport：`width=device-width, initial-scale=1`
  - 写上之后，排版用的宽度才是设备的宽度
- [ ] 百分比是相对谁的
  - 宽度的百分比，相对父元素的内容宽度
  - 高度的百分比，要父元素自己有明确高度才生效
  - 外边距、内边距的百分比，也相对父元素的宽度，不是相对高度
  - 父元素的宽度还没定，子元素的百分比就没有参照
- [ ] em 跟着这块的字号，rem 跟着整页
  - `em` 相对这个元素自己的字号
  - `rem` 相对根元素 `html` 的字号
  - 整页的字号、大块的间距，用 `rem`
  - 某一小块里要跟着这块的字号一起变，可以用 `em`
  - 每一层都用 `em`，倍数会乘上去，尺寸越来越大
- [ ] 按窗口的宽和高来取值
  - `1vw` 是窗口宽度的百分之一
  - `1vh` 是窗口高度的百分之一
  - 想要一块和屏幕一样高，可以写 `100vh`
  - 手机地址栏伸出来、缩回去时，`100vh` 可能比眼前看见的区域更高
- [ ] 屏幕够宽，才用这组样式
  - `@media (min-width: 720px)` 里面的声明，只在窗口够宽时生效
  - 先写窄屏幕的样式，再用更大的宽度往上加
  - 里面只写真正要变的那几条
  - 窗口没那么宽，里面的声明整段不参与
- [ ] 在页面开始挤的地方设断点
  - 把窗口从窄拉到宽，在内容开始挤、重叠、或一行变得过空的地方设断点
  - 这张课程页先做三档：一列、两列、内容宽到一定程度就不再变宽
  - 断点看的是这张页面，不背一套所有网站通用的像素
  - 用浏览器的设备模式来看
- [ ] 图片不要撑破旁边的容器
  - 给 `img` 写 `max-width: 100%`，它就不会比父元素更宽
  - `height: auto` 保住原来的比例
  - HTML 上不再写一个大于容器的死宽度
  - 背景图的缩放用 `background-size`，和这里不是同一个属性

### 做成一张课程介绍页

先补这张页面会反复用到的几件外观：同一种颜色只写一次、一层浅阴影、内容栏居中、悬停时的过渡、链接做成按钮。再装到同一页：页头导航、首屏、三张卡片、页脚。不写脚本。

- [ ] 同一种颜色只写一次
  - 自定义属性以 `--` 开头，例如 `--brand`
  - 定义在 `html` 上，整页都能用
  - 用的时候写 `var(--brand)`
  - 按钮、链接、标题用到同一种颜色，都去引用它
- [ ] 给盒子加一层浅阴影
  - `box-shadow` 按水平偏移、垂直偏移、模糊、颜色来写
  - 模糊越大，边缘越淡
  - 加上 `inset`，阴影朝盒子里面
  - 这一篇只做一层向外的浅阴影，把卡片和页面分开
- [ ] 一栏内容停在页面中间
  - 用一个容器把这一栏包起来
  - `max-width` 限制最宽能到多少，避免一行字拉得太长
  - 左右 `margin` 写成 `auto`，这一栏水平居中
  - 容器再留左右内边距，窄屏幕上字不会贴边
- [ ] 悬停时，颜色慢慢变化
  - `transition` 写上哪个属性要变，以及花多长时间
  - 时间用秒，例如 `0.2s`
  - 过渡写在元素自己身上；新的颜色写在 `:hover` 和 `:focus` 上
  - 只过渡颜色、背景和阴影
- [ ] 把链接做成按钮的样子
  - 元素仍然是 `a`，只改外观
  - 设成 `inline-block` 或 `inline-flex`，上下的内边距才稳定
  - 去掉下划线，加上背景色、文字色和圆角
  - 鼠标放上去、键盘焦点落上来，都要有看得见的变化
- [ ] 课程介绍页：先只写结构
  - 用 `header`、`nav`、`main`、`footer` 分出四个区域
  - 首屏里有一个 `h1`、一句说明、一个链接
  - 中间一节放三张特性，每张有标题和一段文字
  - 这一篇不写外观，只看默认从上往下的顺序对不对
- [ ] 课程介绍页：页头和首屏
  - 页头做成左边商标、右边菜单
  - 首屏的标题、说明和按钮从上往下排，并居中
  - 按钮用已经写好的按钮外观
  - 三张卡片这一篇先不排
- [ ] 课程介绍页：三张卡片
  - 宽屏幕上用最小宽度自动决定一排放几张
  - 每张卡片同一套样子：内边距、圆角、浅阴影
  - 卡片里的图片不超过卡片的宽度
  - 容器变窄，列数自己减少
- [ ] 课程介绍页：接上页脚
  - 页脚放版权，和一组文字链接
  - 整页接上「内容少时页脚仍在窗口底部」
  - 页脚里的链接保持普通链接，不做成主按钮
  - 内容区限制最大宽度，并水平居中
- [ ] 课程介绍页：窄屏幕怎么排
  - 导航在窄屏幕上改成从上往下
  - 首屏的文字和按钮留在屏幕里面
  - 最窄的时候，卡片变成一列
  - 这些变化只写在媒体查询里
