# div 包一块，span 包几个字

## 简单示例（div、span）

`div` 自己占一块，用来包住一组内容。`span` 用在一句话里面，包住其中几个字。外壳不动，`body` 换成下面这样，保存，刷新。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>div 和 span</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <div class="card">
    <h2>这门课先写结构</h2>
    <p>标题、段落和列表先放在这一块里。</p>
  </div>
  <p>读的时候请看清<span class="term">结构</span>这两个字。</p>
</body>
</html>
```

`div` 里的标题和段落上下叠在一起，这块从新的一行开始。`span` 包住的「结构」仍留在这句话中间，没有另起一行。页面上看不出 `class` 的名字。`class` 只是先给这块起个名，颜色和边框以后再用。

## 标签介绍（概念和特征）

两个标签都不表示「这是标题」「这是一段」或「这是导航」。它们只负责包住。已经有更合适的标签时，用那个标签：题目用 `h1`，一段话用 `p`，能点的字用 `a`，一组条目用 `ul` 或 `ol`。示例里的标题仍是 `h2`，没有改成 `div`。

| | `div` | `span` |
|---|---|---|
| 包住什么 | 一组内容，例如一个标题加一段话 | 一句话里的几个字 |
| 自己占不占一块 | 占一块，从新的一行开始 | 不占一块，留在行内 |
| 自己表示什么角色 | 不表示 | 不表示 |

只是为了包一层、里面没有自己的标题，用 `div`。里面有标题、而且是页面上的一节，后面「一篇文章，和其中的一节」会改用 `section`。整页的页头、正文、页脚也有专门的标签，下一篇再换。

`class` 写在开始标签里，用来给这些普通容器起名字。同一类可以共用一个名字，例如很多张卡片都写 `class="card"`。名字用英文单词，中间不要有空格；一个元素要两个名字时，写在同一个 `class` 里，用空格分开，例如 `class="card intro"`。这一篇不写样式。后面写 CSS 时，靠这个名字把卡片和别的 `div` 区分开。

`span` 同样可以加 `class`。它和 `strong`、`em` 的差别是：`span` 不表示重要，也不表示重读，只是先把几个字圈出来，等样式去找。这几个字如果确实更重要，用回 `strong`。

## 要点总结

1. `div` 自己占一块，包住一组内容。`span` 留在一句话里，包住几个字。
2. 两个标签本身不表示标题、段落或导航。
3. 已经有 `h1`、`p`、`a`、`ul` 这类更合适的标签时，用那个标签。
4. 后面写样式时，用 `class` 给这些普通容器起名字。这一篇只起名，不写样式。
