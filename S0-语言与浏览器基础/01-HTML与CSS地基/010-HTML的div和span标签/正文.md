# div 和 span 有什么区别？零基础看懂块级与行内元素

**`div` 和 `span` 都是 HTML 里的普通容器标签，本身不表示任何语义，区别只在于默认的排版方式：`div` 是块级元素，默认独占一行；`span` 是行内元素，默认和前后的文字排在同一行。**

本文解决一个具体问题：写页面的时候，什么时候该用 `div`，什么时候该用 `span`，以及怎么用才不出错。

## div 和 span 的三个区别

`div` 和 `span` 长得几乎一样，都是一对尖括号包住内容。真正把它们区分开的是三件事。

| 对比项 | `div` | `span` |
|---|---|---|
| 默认排版 | 块级，独占一行 | 行内，和文字排在一起 |
| 能包住什么 | 一组内容，比如标题加段落 | 一句话里的几个字 |
| 是否表示语义 | 不表示 | 不表示 |

注意第三行：`div` 和 `span` 都不表示语义。`div` 不是标题，`span` 也不是。它们只做分组，含义全靠里面的标签和 `class`。

## div 和 span 写出来的差别

把下面存成 `index.html`，用浏览器打开。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>div 和 span</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <div class="card">
    <h2>这门课先写结构</h2>
    <p>标题、段落和列表先放在这一块里。</p>
  </div>
  <p>读的时候请看清<span class="term">结构</span>这两个字。</p>
</body>
</html>
```

这段代码演示的是同一个页面上两种容器的排版结果。跑完你会看到：`div` 包住的标题和段落上下叠在一起，这一块从新的一行开始；`span` 包住的「结构」两个字仍留在那句话中间，没有另起一行。

页面上看不出 `class` 的名字，这是正常的。`class` 只是先给这块内容起个名，颜色和边框以后再用样式来做。

## 为什么 span 不独占一行

这背后是 HTML 的默认排版规则，不是这两个标签的特殊设计。

浏览器默认给 `div` 套上块级样式（`display: block`），给 `span` 套上行内样式（`display: inline`）。块级元素自己占满一行，行内元素跟着周围的文字流动。

所以「`div` 自己占一块，`span` 不占块」这句话里的「一块」，指的是**占一行**，不是「包住一块内容」。这两个意思容易混。

后面讲 `display` 属性时会专门讲怎么改这个默认身份。这一篇先记住：`div` 默认独占一行，`span` 默认留在行内。

## 什么时候用 div，什么时候用 span

判断顺序是：先看有没有更合适的标签，没有再选 `div` 或 `span`。

**先找更合适的标签。** 页面上的标题用 `h1` 到 `h6`，段落用 `p`，链接用 `a`，列表用 `ul` 和 `li`。这些标签既有默认样式，也带着语义，屏幕阅读器和搜索引擎都认。

**需要包住一组独立内容，用 `div`。** 比如一个卡片、一个章节、一个页脚区域。它本身要能独立成块，内部可以放任意内容。

**需要在一句话里圈出几个字，用 `span`。** 比如给一个词加背景色、标出重点。它跟着文字流动，不打断句子。

**`span` 和 `strong`、`em` 的区别。** `span` 不表示重要，也不表示重读，只是先把几个字圈出来，等样式去找。如果这几个字确实更重要，用 `strong`；确实要重读，用 `em`。

## 要点总结：记住这三条

1. `div` 和 `span` 都不表示语义，区别只在默认排版：`div` 块级独占一行，`span` 行内留在文字中。
2. 有更合适的标签就用那个。`div`、`span` 是没有更好选择时的兜底。
3. `span` 不等于强调。要强调用 `strong`，要重读用 `em`。
