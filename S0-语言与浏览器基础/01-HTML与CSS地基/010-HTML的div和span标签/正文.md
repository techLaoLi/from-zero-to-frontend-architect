# div 包一块，span 包几个字

## 简单示例（div、span）

`div` 自己占一块，用来包住一组内容。

`span` 用在一句话里面，包住其中几个字。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>div 和 span</title>
</head>
<body>
  <h1>前端从零到架构师</h1>
  <div class="card">
    <h2>这门课先写结构</h2>
    <p>标题、段落和列表先放在这一块里。</p>
  </div>
  <p>读的时候请看清<span class="term">结构</span>这两个字。</p>
</body>
</html>
```

`div` 里的标题和段落上下叠在一起，这块从新的一行开始。

`span` 包住的「结构」仍留在这句话中间，没有另起一行。页面上看不出 `class` 的名字。

`class` 只是先给这块起个名，颜色和边框以后再用。

## 标签介绍（概念和特征）

`div` 和 `span` 都表示包住一块东西。

但是，从使用场景上看，`div` 一般包裹的是一组结构，而 `span` 一般包裹的是一个句子里的几个字。

在真正的浏览器里， `div` 和 `span` 的定义有区别：`div` 是块级元素， `span` 是行内元素。

什么是块级元素、什么是行内元素，这个概念后面会讲。

| | `div` | `span` |
|---|---|---|
| 包住什么 | 一组内容，例如一个标题加一段话 | 一句话里的几个字 |
| 自己占不占一块 | 占一块，从新的一行开始 | 不占一块，留在行内 |
| 自己表示什么角色 | 不表示 | 不表示 |

`class` 写在开始标签里，用来给这些普通容器起名字。

`span` 同样可以加 `class`，它和 `strong`、`em` 的差别是：`span` 不表示重要，也不表示重读，只是先把几个字圈出来，等样式去找。这几个字如果确实更重要，用回 `strong`。

## 要点总结

1. `div` 自己占一块，包住一组内容。`span` 留在一句话里，包住几个字。
2. 两个标签本身不表示标题、段落或导航。
3. 已经有 `h1`、`p`、`a`、`ul` 这类更合适的标签时，用那个标签。
