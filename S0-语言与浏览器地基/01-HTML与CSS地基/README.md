# 专栏 01 · HTML 与 CSS 地基

> 所属阶段：S0 语言与浏览器地基
> 能力增量：从「会写标签」到「能独立还原一张静态页面」
> 计划篇数：101 篇 ｜ 状态：规划中

读者是零基础。写完应能独立做出一张课程介绍页：页头导航、首屏、三张卡片、页脚，并在窄屏下仍然可读。

带勾选框的是一篇。其下无勾选的缩进是这篇的知识点大纲，不是另一篇。一篇只讲一个机制，大纲 3–5 条；某一条还能单独讲清一套机制，就另开一篇。

## 文章清单

### 模块一：HTML 文档与文字

先让页面里有对的内容。这一模块不写 CSS。

- [ ] HTML 是给浏览器的结构说明
  - HTML 描述页面里有什么，外观交给后面的 CSS
  - 标签、属性、文本内容各是什么
  - 开始标签和结束标签成对出现，嵌套不能交叉
  - 用浏览器直接打开一个 `.html` 文件
- [ ] 文档骨架
  - `<!DOCTYPE html>` 让浏览器用现代方式解析
  - `html`、`head`、`body` 各放什么
  - `charset` 用 UTF-8，`lang` 写成 `zh-CN`
  - `title` 出现在浏览器标签页上
- [ ] 标题和段落
  - `h1` 到 `h6` 表示层级，不是六档字号
  - 一页先只放一个 `h1`，下级标题不跳级
  - `p` 是一段话，段与段之间靠标签分开
  - 浏览器默认的标题大小和段间距，后面再用 CSS 改
- [ ] 强调文字
  - 表示「这段重要」用 `strong`
  - 表示「语气上强调」用 `em`
  - `b` 和 `i` 只表示外观，不表示重要性
  - 改颜色和粗细留给 CSS
- [ ] 空白、换行和分隔线
  - 源代码里连续的空格和换行，页面上会被折成一个空格
  - `br` 是换行，不是新的一段
  - `hr` 表示话题换了
  - 段落间距靠后面的 CSS，不靠多按回车
- [ ] 在页面上写出特殊字符
  - 要显示 `<`、`>` 时写成 `&lt;`、`&gt;`
  - `&amp;` 用来显示 `&`
  - `&nbsp;` 是不换行空格，不能拿来推布局
  - 普通空格和中文标点直接写
- [ ] 链接
  - `a` 的 `href` 决定点开以后去哪
  - 链接文字写成目的地，不写「点击这里」
  - `target="_blank"` 时加上 `rel="noopener"`
  - 没有 `href` 的 `a` 不是链接
- [ ] 相对路径
  - 同目录、子目录、上一级目录怎么写
  - 以 `/` 开头表示从网站根目录开始
  - 以 `https://` 开头是另一台服务器上的地址
  - 路径写错时，先核对地址栏里的最终地址
- [ ] 页内跳转
  - 给目标元素一个 `id`
  - `href="#这个id"` 滚到该元素
  - `id` 在这一页里只能出现一次
  - 跳转目标必须是页面上真实存在的内容
- [ ] 图片
  - `img` 用 `src` 指向图片文件
  - `alt` 写出这张图传递的信息；纯装饰图用空 `alt`
  - 图片加载失败时，读者看到的是 `alt`
  - 显示尺寸放到 CSS 里定，这篇只把图放出来
- [ ] 列表
  - 没有先后的用 `ul`，有步骤或名次的用 `ol`
  - 每一项都是 `li`，`li` 只放在列表里面
  - 列表里可以再嵌一层列表
  - 圆点和数字是浏览器的默认样式
- [ ] div 和 span
  - `div` 单独占一块区域，`span` 用在一段文字内部
  - 这两个标签本身不表达含义
  - 已有合适语义标签时，用语义标签，不用 div 把页面堆满
  - 它们是后面加 `class`、写样式时的普通容器

### 模块二：语义化结构

用有含义的标签替换最外层的无意义盒子。

- [ ] 页头、导航、主体和页脚
  - `header` 是一块内容的开头，`footer` 是收尾信息
  - `nav` 只包一组导航链接
  - `main` 是这页的主体，一页只放一个
  - 页面最外层用这四个标签搭区域
- [ ] 文章和区块
  - `article` 是一块可以单独拿出去读完的内容
  - `section` 是同一个主题下的一节，里面要有标题
  - 没有标题的盒子先不要套 `section`
  - 拿不准时先看「这块能不能单独成篇」
- [ ] 引用
  - 成段引用别人的话用 `blockquote`
  - 句子中间的短引用用 `q`
  - 引用和自己的正文要能区分开
  - 出处用文字写出来
- [ ] 在页面里展示代码
  - 标识一小段代码用 `code`
  - 要保留换行和空格时，用 `pre` 包住 `code`
  - 代码里的 `<` 仍然要转义
  - 等宽字体是浏览器对 `code` 的默认样式
- [ ] 图和说明
  - `figure` 把图和它的说明放在一起
  - `figcaption` 是这张图的标题或解释
  - `alt` 负责图片缺失时的信息，`figcaption` 负责给读者看的说明
  - `figure` 里可以是图片，也可以是一段代码或示意

### 模块三：表格

表格只用来呈现行列数据。

- [ ] 一张数据表
  - `table` 呈现二维数据，页面分栏不用表格
  - `tr` 是一行，`th` 是表头，`td` 是数据
  - `thead` 和 `tbody` 把头和身体分开
  - `caption` 用一句话说明这张表在说什么
- [ ] 单元格合并
  - `colspan` 向右合并若干列
  - `rowspan` 向下合并若干行
  - 被合并掉的位置不再写一个空的 `td`
  - 先在纸上把格子画出来，再写标签

### 模块四：表单

没有后端。提交是否生效，先看地址栏里的查询串。

- [ ] 表单包住一组控件
  - `form` 表示里面这些控件是一起提交的
  - `action` 是提交到哪里，`method` 先用 `get`
  - 提交后，字段会出现在地址栏的查询串里
  - 控件要写在这个 `form` 里面，才算它的字段
- [ ] 文本框和标签
  - 单行文本用 `input type="text"`
  - `label` 的 `for` 对应输入框的 `id`
  - 点标签文字也能把光标放进输入框
  - `placeholder` 是示例，不能代替 `label`
  - `name` 是提交时使用的字段名
- [ ] 密码、多行文本和输入类型
  - 密码用 `type="password"`，页面上不显示原文
  - 邮箱、数字分别用 `type="email"`、`type="number"`，这篇只看控件形态
  - 多行文字用 `textarea`，不用 `input`
  - 对错检查放到后面的校验篇
- [ ] 单选和多选
  - 同一组单选框共享一个 `name`，才能互斥
  - 同一组多选框也共享 `name`，但可以同时选中多项
  - 每个选项有自己的 `value`，提交的是 `value`
  - 每个选项的文字用 `label` 的 `for` 指到对应的 `input`
- [ ] 下拉框
  - `select` 是下拉框，`option` 是其中一个选项
  - 提交时带上被选中项的 `value`
  - `selected` 决定一开始选中哪一项
  - 只能选一个、选项又多时用下拉框
- [ ] 提交按钮
  - `button type="submit"` 提交它所在的表单
  - `type="button"` 只是一个按钮，不会提交
  - `type="reset"` 会清掉已填内容，普通表单先不用
  - 按钮用 `button`，不用 `div` 去伪装
- [ ] 浏览器自带的校验
  - `required` 表示这个字段不能空着提交
  - `type="email"` 会检查像不像一个邮箱
  - `maxlength`、`min`、`max` 限制长度或数值范围
  - 提示由浏览器弹出，还不是自己写的错误文案
- [ ] 一组字段的标题
  - `fieldset` 把相关控件框成一组
  - `legend` 是这一组的标题
  - 适合「联系方式」这种分组
  - 分组仍然属于原来的那一个 `form`
- [ ] 禁用和只读
  - 这篇只讲文本框上的这两个属性
  - `disabled` 不能修改，提交时也不会带上
  - `readonly` 不能修改，提交时仍会带上
  - 用「现在允不允许用户改、要不要提交」来选

### 模块五：媒体与文档头

- [ ] 音频和视频
  - `video` 和 `audio` 的最小可用写法
  - `controls` 显示浏览器自带的播放条
  - 多个 `source` 按顺序给出格式，浏览器选用它能播的那个
  - `autoplay` 常常被浏览器阻止，页面不能依赖它自动出声
- [ ] 网页图标
  - `link rel="icon"` 指向一张 ico 或 png
  - 图标显示在浏览器标签页上
  - 路径规则和前面的相对路径相同
  - 没写时，浏览器还会自己去请求 `/favicon.ico`
- [ ] 标题和描述
  - `title` 是标签页文字，也是搜索结果里的主标题
  - `meta name="description"` 是准备给搜索结果的摘要
  - 搜索引擎不一定原样采用这段摘要
  - 一页一个清楚的 `h1`，比在正文里堆关键词有用

### 模块六：CSS 规则与选择器

从这篇起，样式写进独立的 `.css` 文件。

- [ ] 样式写在独立文件里
  - CSS 负责外观，HTML 负责结构
  - 行内样式、`head` 里的 `style`、外部文件，三种都见过即可
  - 后面的文章都用外部 `.css`
  - `link rel="stylesheet"` 放在 `head` 里
- [ ] 一条样式规则
  - 选择器决定这组样式作用到谁
  - 一条声明是「属性: 值;」
  - 花括号包住一组声明
  - `/* 注释 */` 不会出现在页面上
- [ ] 类和 id
  - `class` 可以加给一组元素，用来复用样式
  - `id` 在一页里只给一个元素
  - CSS 里用 `.类名` 和 `#id` 选中它们
  - 样式复用写 `class`；`id` 留给页内跳转和表单的 `label`
  - 标签和类写在一起，如 `a.button`，表示必须同时满足
- [ ] 元素选择器
  - 写元素名就会选中页面上所有这种元素，如 `p`
  - 逗号把多个选择器写成一组，共用同一套声明
  - 选择器过宽时，会改到没打算改的元素
  - 先在一小段页面上改一种元素，看清范围再扩大
- [ ] 后代和子代
  - 空格是后代选择器：`nav a` 选中导航里面任意一层的链接
  - `>` 是子代选择器，只选下一层
  - 选择器写得越具体，影响范围越小
  - 要改「这一块里面的链接」时，先用后代选择器
- [ ] 悬停和焦点
  - `:hover` 是指针放在元素上
  - `:focus` 是这个元素正在被操作，键盘也能到达
  - 链接、按钮、输入框都要能看出焦点
  - 伪类写在选择器后面，如 `a:hover`
  - 焦点框被去掉之后，要另外给出一眼能看见的焦点样式
- [ ] 谁覆盖谁
  - 同一元素上，行内样式强于 `id`，`id` 强于 `class`，`class` 强于元素选择器
  - 强度相同时，样式表里后出现的声明覆盖先出现的
  - 多个外部文件的先后，由 `link` 的顺序决定
  - 覆盖靠把选择器写清楚，不靠把同一句重复写很多遍
- [ ] 权重和 !important
  - 先比 `id` 的个数，多的赢
  - `id` 相同，再比 `class` 和伪类的个数
  - 再比元素选择器的个数
  - `!important` 会跳过这套比较；这篇先认识它，页面里先不写
- [ ] 继承
  - `color` 和字体相关属性会从父元素传到子元素
  - `margin`、`padding`、`border`、`background` 不继承
  - 子元素写了同名属性，就用子元素自己的值
  - 一整块文字要用同一个颜色时，写在容器上

### 模块七：文字与颜色

- [ ] 颜色的三种写法
  - 颜色名，例如 `black`
  - 十六进制 `#rrggbb`
  - `rgb(红, 绿, 蓝)`，每个分量从 0 到 255
  - 同一份页面里先固定用一种写法
- [ ] 字号、字体和字重
  - `font-size` 决定字有多大
  - `font-family` 按顺序写备用字体，最后写一个通用族，如 `sans-serif`
  - `font-weight` 用 `400` 表示常规，用 `700` 表示粗体
  - 先给 `body` 设一套，标题再单独改
- [ ] 行高和对齐
  - `line-height` 用无单位数字，如 `1.6`，表示字号的倍数
  - `text-align` 决定一行文字在盒子里靠左、居中还是靠右
  - `text-decoration` 加上或去掉划线
  - 段落难读时先调行高

### 模块八：盒模型

- [ ] 盒子的四层
  - 从内到外是内容、`padding`、`border`、`margin`
  - `padding` 是内容和边框之间的距离
  - `margin` 是这个盒子和邻居之间的距离
  - 在浏览器的元素面板里能点开这四层
- [ ] width 到底包含什么
  - 默认 `content-box` 时，`width` 只算内容，`padding` 和 `border` 加在外面
  - `border-box` 时，`width` 把内容、`padding`、`border` 算在一起
  - 页面先写上 `box-sizing: border-box`
  - 盒子比预期更宽时，先看是不是还在用默认算法
- [ ] 上下 margin 会合并
  - 两个上下相邻的块级盒子，垂直 `margin` 会合成一段，取较大的那个
  - 父元素和第一个子元素的上 `margin`，中间没有 `padding` 或 `border` 隔开时也会并到外面
  - 左右 `margin` 不合并
  - 间距少了一截时，先检查是不是合并了
- [ ] 背景色铺在哪
  - `background-color` 铺在内容和 `padding` 下面
  - 默认不铺进 `margin`
  - 背景画在文字和子元素的下面
  - 想要一整块底色时，把颜色写在容器上
- [ ] 背景图怎么放
  - `background-image` 用 `url()` 指向图片
  - `background-size` 先掌握 `cover` 和 `contain`
  - `background-position` 决定图靠哪一边或居中
  - 背景图是装饰，关键信息仍要写在 HTML 里
- [ ] 边框和圆角
  - `border` 按宽度、样式、颜色来写
  - 可以只给某一边加边框
  - `border-radius` 让角变圆
  - 圆角加大到一半高度时，可以得到胶囊形

### 模块九：文档流

- [ ] 块级和行内
  - 块级元素独占一行，可以设置宽度和高度
  - `span`、`a` 这类行内非替换元素，设置宽高通常不起作用
  - `div` 默认是块级，`span` 和 `a` 默认是行内
  - `display` 可以改变元素的这个身份
- [ ] 行内块
  - `inline-block` 留在一行里面，同时可以设置宽高
  - 适合一小排按钮或标签
  - 两个行内块之间的空隙，常常来自 HTML 源码里的换行
  - 要按比例分配一整行时，改用后面的 Flex
- [ ] 正常文档流
  - 块级盒子从上往下排
  - 行内内容在一行里从左往右排，排不下再换行
  - 还在流里的盒子会占住自己的位置
  - 定位才会把盒子从这套排列里拿出去
- [ ] 浮动只需要认识
  - `float` 最初用来让文字绕着图片走
  - 浮动元素离开正常流，父元素可能因此没有高度
  - 旧页面会用浮动做多列
  - 新页面的分栏用 Flex 和 Grid，这里能读懂浮动即可
- [ ] 先改掉会碍事的默认样式
  - `body` 自带一圈 `margin`
  - 链接自带颜色和下划线
  - 列表自带圆点和左侧缩进
  - 只改这一页用到的默认外观

### 模块十：Flex

Flex 管一行或一列。二维的行加列留给 Grid。

- [ ] 打开 Flex
  - `display: flex` 写在父元素上
  - 只有直接子元素变成项目
  - 它处理的是一个方向上的排列
  - 主轴默认从左到右
- [ ] 方向和换行
  - `flex-direction` 把主轴改成横向或纵向
  - 主轴方向变了，后面的「起点、终点」跟着变
  - `flex-wrap: wrap` 允许一行排不下时换到下一行
  - 不换行时，项目会被挤在同一行里
- [ ] 主轴对齐
  - `justify-content` 分配主轴上多出来的空间
  - `flex-start`、`center`、`flex-end` 是整组靠向哪一端
  - `space-between` 让两端贴边，中间的空隙均分
  - 它移动的是项目的位置，不改变单个项目的尺寸
- [ ] 交叉轴对齐
  - 主轴横向时，交叉轴是竖直方向
  - `align-items` 决定项目在交叉轴上靠哪一边，或被拉满
  - 默认 `stretch` 会把项目拉到和容器一样高
  - `align-self` 只改其中一个项目，并覆盖容器上的 `align-items`
- [ ] 多行的行间距
  - `align-content` 只在换行之后、有多行时起作用
  - 它分配的是行与行之间的空间
  - `align-items` 管的是每一行内部项目怎么对齐
  - 只有一行时，改 `align-content` 看不到效果
- [ ] 多余空间怎么分
  - `flex-grow` 默认是 `0`，不拿走多余空间
  - 设为 `1` 的项目参与分配剩余空间
  - 多个项目按 `flex-grow` 的数字比例来分
  - 容器没有剩余空间时，这个值看起来像没写
- [ ] 分配前的基准尺寸
  - `flex-basis` 是分配空间之前，项目先占据的主轴尺寸
  - 值为 `auto` 时，项目上若写了对应方向的宽或高，就用那个值
  - 没写宽高时，`auto` 退回到内容本身的尺寸
  - 它定的是起点，不是最终一定呈现的尺寸
- [ ] 空间不够时怎么缩
  - `flex-shrink` 默认会缩小
  - 设为 `0` 的项目拒绝缩小
  - 几个项目都允许缩时，按比例让出空间
  - 内容溢出容器时，先看相关项目是不是还允许缩小
- [ ] flex 简写
  - `flex: 1` 等于放大 1、缩小 1、基准 `0%`
  - `flex: auto` 等于放大 1、缩小 1、基准 `auto`
  - `flex: none` 等于不放大、不缩小、基准 `auto`
  - 写了简写，就按简写理解，不和三个长属性各写一套互相打架
- [ ] 项目之间的缝
  - `gap` 只出现在项目之间，不加在容器外圈
  - 一个值同时用于行和列，两个值分别是行距和列距
  - 换行之后，行与行之间也使用这个缝
  - 项目间距用 `gap`，不用每个项目的左右 `margin` 去凑
- [ ] 视觉顺序和源码顺序
  - `order` 改变项目在主轴上的视觉先后
  - 默认都是 `0`，数字更小的排在前面
  - 读屏和键盘仍按 HTML 源码顺序移动
  - 只用它调整外观，不用它补救写反了的文档结构
- [ ] 水平垂直居中
  - 父元素设为 `display: flex`
  - `justify-content: center` 负责主轴居中
  - `align-items: center` 负责交叉轴居中
  - 父元素在垂直方向要有高度，否则没有空间可居中
- [ ] 两端对齐的导航
  - 左边商标、右边菜单，用 `space-between`，或给菜单 `margin-left: auto`
  - 菜单自己再作为一层 flex，项与项之间用 `gap`
  - 菜单项是链接
  - 这一篇先做宽屏下一行导航，窄屏留到响应式
- [ ] 等宽的一排
  - 每个项目写同一个 `flex` 值，按同一基准分宽度
  - 项目内部仍按普通文档流排
  - 项目之间的距离用父元素的 `gap`
  - 这一篇固定为一行，换行留到窄屏那篇
- [ ] 页脚贴在视口底部
  - 整页是纵向 flex，最小高度 `100vh`
  - 中间内容区 `flex: 1`，吃掉多余高度
  - 页脚不放大，就落在底部
  - 内容变高时，页脚跟在内容后面，不盖住内容

### 模块十一：Grid

行和列要同时设计时用 Grid。

- [ ] 划出行列
  - `display: grid` 写在父元素上
  - `grid-template-columns` 决定列数和每列宽度
  - `grid-template-rows` 决定行
  - 子元素按源码顺序自动进入格子
  - `gap` 留在轨道之间，网格外圈的留白用 `padding`
- [ ] fr 和 repeat
  - `fr` 是扣掉固定轨道之后，剩余空间里的一份
  - `1fr 1fr 1fr` 把剩余空间分成三等份
  - `repeat(3, 1fr)` 是同一写法的简写
  - 像素和 `fr` 混用时，先扣掉像素，剩下的再按 `fr` 分
- [ ] 最小宽度和自动列数
  - `minmax(240px, 1fr)` 表示这条轨道最窄 240px，有空间再拉宽
  - `repeat(auto-fit, minmax(240px, 1fr))` 按容器宽度决定列数
  - 容器变窄时列数减少，项目往下排
  - 卡片墙先用这一个写法
- [ ] 一个项目占多格
  - `grid-column: span 2` 向右占两列
  - `grid-row: span 2` 向下占两行
  - 被占住的格子，后面的项目会自动让开
  - 跨度不能超过这一行还剩的格子数
- [ ] 用网格线定位
  - 列线从左往右数，从 `1` 开始
  - `grid-column: 1 / 3` 是从 1 号线到 3 号线，中间跨过两列
  - 负数线号从右边往回数
  - `span` 表示占几格，线号表示从哪条线到哪条线
- [ ] 给区域起名字
  - `grid-template-areas` 用每一行的字符串画出区域
  - 同一个名字占住的格子必须连成一块矩形
  - `.` 表示这个格子空着
  - 子元素用 `grid-area` 填上名字，对上页头、侧栏、内容和页脚
- [ ] 格子里的内容怎么对齐
  - `justify-items` 管水平方向，`align-items` 管竖直方向
  - 默认 `stretch` 会把项目拉满它所在的格子
  - 这里对齐的是格子内部，和 Flex 里同名属性不是同一个作用对象
  - 单个项目的例外用 `justify-self` 和 `align-self`

### 模块十二：定位与层叠

- [ ] 五种定位各管什么
  - `static` 是默认，按文档流排，`z-index` 对它无效
  - `relative` 相对自己原来的位置偏移，原来的位子还留着
  - `absolute` 和 `fixed` 离开文档流
  - `sticky` 在到达阈值之前仍留在文档流里
  - 这篇只分清五种各自的参照，细节在后面几篇
- [ ] 相对定位
  - `position: relative` 配上 `top`、`right`、`bottom`、`left` 做偏移
  - 偏移量相对的是它本来要待的位置
  - 原来的空位还在，后面的兄弟不会过来填
  - 它常常只负责当绝对定位子元素的参照，自己可以不偏移
- [ ] 绝对定位找谁当参照
  - `position: absolute` 离开文档流，不再撑开父元素的高度
  - 参照物是最近的、`position` 不是 `static` 的祖先
  - 祖先都没有定位时，参照初始包含块
  - 子元素跑到页面角落时，先给父元素加上 `position: relative`
- [ ] 相对视口钉住
  - `position: fixed` 相对视口，页面滚动时它仍留在屏幕的那个位置
  - 它离开文档流，原来的位置不保留
  - 顶栏钉住时，后面的内容要留出顶栏的高度
  - 祖先上的 `transform` 会改变它的参照，外层先不要加
- [ ] 吸顶
  - `position: sticky` 在滚过阈值前仍占着文档里的位置
  - `top: 0` 表示距离视口顶部为 0 时吸住
  - 吸住之后，它跟着视口走
  - 祖先的 `overflow` 不是 `visible` 时，吸顶常常失效
- [ ] 默认谁盖住谁
  - 都在正常流里时，后写的兄弟画在先写的兄弟上面
  - 元素的背景画在自己的文字和子元素下面
  - 元素还是 `static` 时，`z-index` 不生效
  - 要控制叠放，先给元素一个非 `static` 的定位
- [ ] z-index 比的是同一层
  - 比较的是已经定位的元素
  - 数字大的在上面，数字可以是负数
  - 比较只发生在同一个层叠上下文里面
  - 父元素已经形成新的上下文时，子元素的 `z-index` 不能穿出这个父元素
- [ ] 什么时候会多出一个层叠上下文
  - `opacity` 小于 1 会新建一个上下文
  - `transform` 不是 `none` 会新建一个上下文
  - Flex 或 Grid 的项目只要 `z-index` 不是 `auto`，也会新建
  - 子元素的层级出不去时，先检查父元素有没有这三类情况

### 模块十三：响应式

- [ ] 视口
  - 视口是浏览器里真正用来排这一页的区域
  - 没有 viewport 声明时，手机常常按大约 980px 的宽度来排，再整页缩小
  - `meta name="viewport"` 写成 `width=device-width, initial-scale=1`
  - 写上之后，布局所用的宽度才等于设备宽度
- [ ] 百分比相对谁
  - 宽度的百分比相对父元素的内容宽度
  - 高度的百分比，只有父元素自己有明确高度时才生效
  - `margin` 和 `padding` 的百分比也相对父元素的宽度
  - 父元素宽度没定，子元素的百分比就没有参照
- [ ] em 和 rem
  - `em` 相对当前元素自己的字号
  - `rem` 相对根元素 `html` 的字号
  - 整页字号用 `rem`，某一块内部的间距可以用 `em`
  - 每一层都用 `em` 相乘，尺寸会越来越大
- [ ] vw 和 vh
  - `1vw` 是视口宽度的百分之一
  - `1vh` 是视口高度的百分之一
  - 整屏区域可以用 `100vh`
  - 手机浏览器的地址栏伸缩时，`100vh` 可能比看得见的区域更高
- [ ] 媒体查询怎么写
  - `@media (min-width: ...)` 里的声明，只在视口足够宽时生效
  - 先写窄屏样式，再用更大的 `min-width` 往上加
  - 查询里面只写需要变化的声明
  - 条件不满足时，里面的声明整段不参与
- [ ] 断点按页面来定
  - 把视口从窄拉到宽，在内容开始挤、重叠或一行过稀的地方设断点
  - 这一页先做三档：一列、两列、内容宽度封顶
  - 断点看这张页面，不背一套万能像素
  - 用浏览器的设备模式查看
- [ ] 图片跟着容器缩
  - `img` 设 `max-width: 100%`，不超出父元素
  - `height: auto` 保住图片比例
  - HTML 上不再写一个大于容器的死宽度
  - 背景图的缩放用 `background-size`，和 `img` 的这条规则不是同一个属性

### 模块十四：组装一张课程介绍页

先补三个后面要反复用的外观做法，再把前面的机制装到同一张页面上。页面包含页头导航、首屏、三张特性卡片、页脚。不写脚本，不做汉堡菜单。

- [ ] 把重复的颜色收成变量
  - 自定义属性以 `--` 开头
  - 定义在 `html` 上，整页都能用
  - 使用时写 `var(--name)`
  - 同一种颜色只定义一次，按钮、链接和标题去引用它
- [ ] 一层浅阴影
  - `box-shadow` 按水平偏移、垂直偏移、模糊半径、颜色来写
  - 模糊越大，边缘越淡
  - `inset` 表示阴影朝盒子内侧
  - 这篇只做一层向外的浅阴影
- [ ] 内容区居中
  - 用一个容器把一块内容包起来
  - `max-width` 限制阅读宽度
  - 左右 `margin` 设为 `auto`，容器水平居中
  - 容器自己再留左右 `padding`，文字在窄屏上不贴边
- [ ] 悬停时的过渡
  - `transition` 写上要变化的属性和时长
  - 时长用秒，例如 `0.2s`
  - 过渡写在元素自己身上，新的颜色或背景写在 `:hover` 和 `:focus` 上
  - 只过渡颜色、背景和阴影
- [ ] 把链接做成按钮
  - 元素仍然是 `a`，只改变外观
  - 用 `inline-block` 或 `inline-flex`，内边距才稳定
  - 去掉下划线，设置背景、文字色和圆角
  - `:hover` 和 `:focus` 都要有可见变化
- [ ] 课程介绍页：只写结构
  - 用 `header`、`nav`、`main`、`footer` 搭出四个区域
  - 首屏里有一个 `h1`、一句说明、一个链接
  - 中间一节放三张特性，每张有标题和一段文字
  - 这一篇不写外观，只检查默认文档流里的顺序对不对
- [ ] 课程介绍页：页头和首屏
  - 页头接上两端对齐的导航
  - 首屏的标题、说明和按钮纵向排列并居中
  - 按钮使用已经写好的按钮外观
  - 这一篇不处理三张卡片
- [ ] 课程介绍页：三张卡片
  - 宽屏下一排三张，使用 `auto-fit` 和 `minmax`
  - 每张卡片共用同一套 class：内边距、圆角、浅阴影
  - 卡片里的图片不超过卡片宽度
  - 容器变窄时列数自动减少
- [ ] 课程介绍页：接上页脚
  - 页脚放版权和一组文字链接
  - 整页接上「页脚贴在视口底部」的纵向 flex
  - 页脚链接保持普通链接，不做成主按钮
  - 内容区套上最大宽度和水平居中
- [ ] 课程介绍页：窄屏调整
  - 导航在窄屏改为纵向排列
  - 首屏文字和按钮留在屏幕里面
  - 卡片在最窄的一档变成一列
  - 这些变化只写在媒体查询里
