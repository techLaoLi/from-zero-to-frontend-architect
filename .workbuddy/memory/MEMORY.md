## 正文结构（2026-10-26 用户定稿，不可擅改）

每篇 `正文.md` 固定 5 节，顺序体现「先看懂 → 再说准 → 后记住」：

1. `## 1. 基本概述` — 新手引导，从现象切入，给直觉 + 类比，不出现术语定义，300–600 字
2. `## 2. 专业定义` — 一句可复述的正式定义，拆关键词，补术语对照与适用边界
3. `## 3. 代码示例` — 能跑的最小例子，先能跑再加一层
4. `## 4. 知识小结` — 一张图或表收束 + 两三处易错点（现象 → 原因 → 做法）
5. `## 5. 必须掌握` — 3–5 条可背诵的话

- 原来的「先看一个问题 / 三个常见坑 / 一张图小结 / 下一篇预告」四节已废弃，坑并入第 4 节。
- 连载衔接只在文末加一行 `> 下一篇：...`，不单独成节。
- 同步落点：`AGENTS.md`（正文模板）、`README.md`（单篇文章标准模板 + 版本记录）。
