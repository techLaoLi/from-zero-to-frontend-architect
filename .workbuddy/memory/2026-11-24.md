抓了 4 篇已发布文章对照。额外发现两个诊断没提但更致命的问题：

1. **15 篇小标题全是同一套模板句**（「简单示例（div、span）」「标签介绍（概念和特征）」「要点总结」）。零搜索价值，AI 也无法据此拆知识块。根因在专栏 README 的**大纲层**，不在正文层。

曾怀疑「CSDN 把 Markdown 表格渲染塌了」，**实测不成立**：另抓两篇有表格的 CSDN 文章，表格同样被压成连续纯文本，说明是抓取工具的 HTML→Markdown 转换行为，CSDN 页面上的表格正常渲染。这条不用改。

### 踩过的坑

1. **PingFang.ttc 在当前 macOS（26.6.2）已不存在**，`/System/Library/Fonts/PingFang.ttc` 找不到。改用 `STHeiti Medium.ttc` index=1（Heiti SC Medium）。原主图脚本在 /tmp 已丢失，重写后入库到 `tools/gen_cover.py`。
2. **写了一个通用批量改写脚本 `upgrade_articles.py`，有严重 bug 已删除**：它按位置把小标题映射到新标题，当新旧小节数量不一致时内容会整体错位（001 把「整体说明」和「分工」对调了）。**这类内容重排必须逐篇人工做**，脚本只适合做 H1 + 主图这种机械同步。
3. **主图断行**：原来按字硬断，「是什么」被拆开。改为优先在标点后断行，且在所有标点断点里选两行宽度差最小的。
4. **主图要 `html.unescape`**：标题里的 `&lt; &gt; &amp;` 得显示成真实的 `< > &`。
5. **主图垂直居中**：不能按行高算，要先画到透明图层再按实际墨迹 bbox 居中，否则字体上留白导致偏上。
